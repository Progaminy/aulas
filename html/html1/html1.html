⚙️ Instalações Necessárias

Para instalar o ambiente de desenvolvimento para HTML - CSS, siga os passos abaixo:

  1. Instale um editor de texto ou IDE (Visual Studio Code);
  2. Instale um navegador web moderno (Google Chrome);
  3. Configure o ambiente de desenvolvimento (Extensões Português, word wrap);
  4. Baixe e instale editor de imagem para reduzir e definir formatos (GIMP);
  5. Baixe e instale um editor de áudio para editar e definir formatos (Audacity);
  6. Baixe e instale um editor de vídeo para editar e definir formatos (DaVinci Resolve, HandBrake).

📌 TAGS DO CÓDIGO BASE HTML

  1. A tag <!DOCTYPE html> é usada para declarar o tipo de documento e a versão do HTML que está sendo usada. Ela deve ser a primeira linha do código HTML e informa ao navegador como interpretar o conteúdo da página.
  2. A tag <html> é a tag raiz de um documento HTML e contém todos os elementos do documento.
  3. A tag <head> é usada para conter informações sobre o documento, como o título e meta tags.
  4. A tag <body> é usada para conter o conteúdo visível da página web.
