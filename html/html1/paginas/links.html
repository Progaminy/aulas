🔗 Links

🏠 Link Interno

Para criar um link interno ou páginas, seguimos os seguintes passos:

  • Criar novo arquivo HTML
  • Utiliza-se a tag <a>
<a href="caminho/arquivo.html" rel="next"> Clique aqui para a próxima página </a>

🌐 Link Externo

<a href="https://www.exemplo.com" target="_blank" rel="external"> Clique aqui para visitar o exemplo </a>

🔒 Link para Limitar Busca de Link Externo

Para criar um link externo, você pode usar a tag <a> com o atributo href apontando para a URL do recurso externo. Por exemplo:

<a href="https://www.exemplo.com" target="_blank" rel="nofollow"> Clique aqui para visitar o exemplo </a>

⬇️ Link para Baixar Arquivos

Consulte os formatos de mídia disponíveis:

Ou clique nos links: formatosMidias.html | IANA.org

Para criar um link para baixar um arquivo, você pode usar a tag <a> com o atributo href apontando para o caminho do arquivo que deseja disponibilizar para download. Por exemplo:

<a href="caminho/arquivo" download="nome-do-arquivo" type="application/formato"> Clique aqui para baixar o arquivo </a>

Exemplo:

<a href="../arquivos/arquivo.pdf" download="arquivo.pdf" type="application/pdf">baixar arquivo pdf</a>
