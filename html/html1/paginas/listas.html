📋 Listas

🔢 Lista Ordenada

Para criar lista ordenada utiliza-se a tag:

<ol> itens </ol>

Para cada item da lista utiliza-se a tag:

<li> </li>

🔄 Mudar Tipo de Contagem de Ordenadas

Para mudar o tipo de contagem de uma lista ordenada, você pode usar o atributo type na tag <ol>. O atributo type pode ter os seguintes valores:

<ol type="1"> - para contagem numérica (padrão)

<ol type="a"> - para contagem alfabética minúscula

<ol type="A"> - para contagem alfabética maiúscula

<ol type="i"> - para contagem romana minúscula

<ol type="I"> - para contagem romana maiúscula

📍 Começar a Contagem em uma Determinada Posição

Para começar a contagem de uma lista ordenada em uma determinada posição, você pode usar o atributo start na tag <ol>. O atributo start especifica o número inicial da contagem. Por exemplo:

<ol start="5"> <li> Item 5 </li> <li> Item 6 </li> <li> Item 7 </li> </ol>

🔘 Lista Não Ordenada

Para criar uma lista não ordenada, utiliza-se a tag <ul>. Para cada item da lista, utiliza-se a tag <li>. Por exemplo:

<ul> <li> Item 1 </li> <li> Item 2 </li> <li> Item 3 </li> </ul>

🔄 Mudar Tipo de Marcador de Lista Não Ordenada

Para mudar o tipo de marcador de uma lista não ordenada, você pode usar o atributo type na tag <ul>. O atributo type pode ter os seguintes valores:

<ul type="disc"> - para marcador de disco (padrão)

<ul type="circle"> - para marcador de círculo

<ul type="square"> - para marcador de quadrado

<ul type="none"> - para nenhum marcador

🔗 Junção de Listas

Para juntar listas, você pode utilizar a tag <ol> ou a tag <ul> dentro de outra tag <ol> ou a tag <ul> criando uma lista aninhada. Por exemplo:

<ol> <li> lista 1 </li> <ul> <li> lista 1.1 </li> <li> lista 1.2 </li> </ul> <li> lista 2 </li> <ul> <li> lista 2.1 </li> <li> lista 2.2 </li> </ul> </ol>

📖 Lista de Definição

Para criar uma lista de definição, utiliza-se a tag <dl>. Para cada termo a ser definido, utiliza-se a tag <dt>, e para cada definição, utiliza-se a tag <dd>. Por exemplo:

<dl> <dt> Termo 1 </dt> <dd> Definição do termo 1 </dd> <dt> Termo 2 </dt> <dd> Definição do termo 2 </dd> </dl>
