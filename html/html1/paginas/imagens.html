Inserir Imagem

Para colocar imagem use a seguinte tag:

Para carregar uma imagem em HTML, você pode usar a tag <img>. A sintaxe básica para usar essa tag é a seguinte:

<picture> <img src="caminho/para/imagem.jpg" alt="Descrição da imagem"> <img src="caminho/para/imagem.png" alt="Descrição da imagem"> <picture>

📝 Notas Importantes

Nota A:

É recomendado fornecer várias fontes de imagem em diferentes formatos para garantir a compatibilidade com diferentes navegadores, pois nem todos os navegadores suportam os mesmos formatos de imagem.

Onde:

  • src: Especifica o caminho para a imagem que você deseja carregar. Pode ser um caminho relativo ou absoluto.
  • alt: Fornece uma descrição alternativa da imagem, que é exibida caso a imagem não possa ser carregada ou para leitores de tela.

🌐 Carregar Imagens Externas

Para carregar uma imagem externa, você pode usar a tag <img> com o atributo src apontando para a URL da imagem. Por exemplo:

<img src="https://www.exemplo.com/imagem.jpg" alt="Descrição da imagem">

⚠️ Nota:

Isso carregará a imagem diretamente do site externo. Certifique-se de que a URL da imagem seja válida e que você tenha permissão para usá-la.

⬇️ Baixar Imagem

Para baixar uma imagem, você pode usar a tag <a> com o atributo href apontando para o caminho da imagem e o atributo download para indicar que o link é para download. Por exemplo:

<a href="caminho/para/imagem.jpg" download>Baixar Imagem</a>
