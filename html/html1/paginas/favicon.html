🌟 Favicon

📌 Como Inserir um Favicon

Para colocar um favicon em seu site, você pode usar a tag <link> no cabeçalho do seu documento HTML. A sintaxe básica para usar essa tag é a seguinte:

<link rel="icon" href="caminho/para/favicon.ico" type="image/x-icon">

Onde:

  • rel: Especifica a relação entre o documento atual e o recurso vinculado. Para favicons, use "icon".
  • href: Especifica o caminho para o arquivo de ícone que você deseja usar como favicon. Pode ser um caminho relativo ou absoluto.
  • type: Especifica o tipo MIME do recurso vinculado. Para favicons, use "image/x-icon".

📄 Exemplo de Código HTML com Favicon

<!DOCTYPE html> <html lang="pt-br"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Document</title> <link rel="icon" href="caminho/para/favicon.ico" type="image/x-icon"> </head> <body> <!-- Conteúdo da página --> </body> </html>

📝 Explicação do Código

Substitua "caminho/para/favicon.ico" pelo caminho real para o seu arquivo de ícone. Depois de adicionar essa linha ao seu código HTML, o favicon deve aparecer na guia do navegador quando os usuários visitarem seu site.

⚠️ Observação

Para que o favicon seja exibido corretamente, certifique-se de que o arquivo de ícone esteja no formato .ico e que o caminho especificado na tag <link> esteja correto.
