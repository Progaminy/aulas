📌 Como Inserir Áudio

Para colocar um áudio use a seguinte tag:

<audio controls preload="metadata"> <source src="audio/audio.mp3" type="audio/mpeg"> <source src="audio/audio.ogg" type="audio/ogg"> <source src="audio/audio.wav" type="audio/wav"> <source src="audio/audio.aac" type="audio/aac"> <source src="audio/audio.flac" type="audio/flac"> <source src="audio/audio.opus" type="audio/opus"> <source src="audio/audio.webm" type="audio/webm"> </audio>

Nota A:

O atributo controls é usado para exibir os controles de reprodução do áudio, como play, pause e volume.
O atributo preload="metadata" indica que o navegador deve carregar apenas os metadados do áudio, como duração e informações de formato, sem carregar o arquivo completo até que seja necessário.

Nota B:

É recomendado fornecer várias fontes de áudio em diferentes formatos para garantir a compatibilidade com diferentes navegadores, pois nem todos os navegadores suportam os mesmos formatos de áudio.

⬇️ Como Baixar Áudio

Para baixar áudio, usa-se a tag <a> com o atributo href apontando para o arquivo de áudio.

<a href="audio/audio.mp3" type="audio/mp3" download>Baixar áudio</a>
