A propriedade `box-shadow` adiciona uma ou mais sombras a um elemento HTML. A sombra é desenhada fora da borda do elemento (por padrão), seguindo o formato definido pela propriedade `border-radius`. #### Para que serve? - **Criar Profundidade (Elevação):** Fazer um elemento parecer que está flutuando sobre o fundo. É essencial para cards, modais (pop-ups) e menus dropdown. - **Destacar Elementos:** Dar foco visual a um botão ou campo de formulário. - **Efeitos Decorativos:** Criar um brilho externo (glow), contornos duplos ou um efeito "neon". - **Simular Relevo:** Com sombras internas (`inset`), podemos simular um elemento pressionado ou afundado. #### Sintaxe Detalhada A forma completa da propriedade é: ```css box-shadow: offset-x offset-y blur-radius spread-radius color inset; ``` Vamos dissecar cada valor: 1. **`offset-x` (Obrigatório):** - **Significado:** O deslocamento horizontal da sombra. - **Valores:** Um valor CSS de comprimento (ex: `10px`, `-5px`, `0`). - **Detalhe:** Valores positivos movem a sombra para a **direita**. Valores negativos movem para a **esquerda**. 2. **`offset-y` (Obrigatório):** - **Significado:** O deslocamento vertical da sombra. - **Valores:** Um valor CSS de comprimento. - **Detalhe:** Valores positivos movem a sombra para **baixo**. Valores negativos movem para **cima**. 3. **`blur-radius` (Opcional - Padrão: 0):** - **Significado:** O raio do desfoque da sombra. Quanto maior o valor, mais "borrada" e suave a sombra fica. - **Valores:** Um valor CSS de comprimento **não-negativo** (ex: `5px`, `20px`). `0` significa uma sombra totalmente nítida. - **Detalhe:** É um valor crucial para o realismo. Sombras na vida real raramente são perfeitamente nítidas. 4. **`spread-radius` (Opcional - Padrão: 0):** - **Significado:** O raio de expansão ou contração da sombra. Ele muda o tamanho da sombra sem alterar seu desfoque. - **Valores:** Um valor CSS de comprimento. - **Detalhe:** Valores positivos **expandem** a sombra, tornando-a maior que o elemento. Valores negativos **contraem** a sombra. Isso é útil para simular sombras muito próximas a um lado ou criar bordas múltiplas. 5. **`color` (Opcional - Padrão: `currentColor`):** - **Significado:** A cor da sombra. - **Valores:** Qualquer valor de cor CSS válido (nome, hexadecimal, `rgb()`, `rgba()`, `hsl()`, `hsla()`). - **Detalhe:** O uso de `rgba()` ou `hsla()` é fortemente recomendado, pois permite controlar a opacidade da sombra, tornando-a mais realista. Ex: `rgba(0, 0, 0, 0.2)`. 6. **`inset` (Opcional - Padrão: outset):** - **Significado:** Uma palavra-chave que transforma a sombra de externa (padrão) para interna. - **Valores:** `inset` ou nada. - **Detalhe:** Uma sombra `inset` é desenhada *dentro* das bordas do elemento, no conteúdo e no padding. É perfeita para criar um efeito de "afundado". #### Exemplos Explicados de `box-shadow` ```html

A forma da sombra segue precisamente o contorno das letras (glifos). #### Para que serve? - **Legibilidade:** Criar contraste para texto sobre imagens. Uma sombra escura sob texto claro ou vice-versa. - **Efeitos Tipográficos:** Criar texto com efeito "3D", "entintado" (letterpress), brilhante (neon) ou com um "fantasma". - **Decoração:** Simplesmente embelezar títulos e cabeçalhos. #### Sintaxe Detalhada A forma completa é muito parecida com `box-shadow`, mas com menos parâmetros: ```css text-shadow: offset-x offset-y blur-radius color; ``` 1. **`offset-x`:** Deslocamento horizontal (obrigatório). 2. **`offset-y`:** Deslocamento vertical (obrigatório). 3. **`blur-radius`:** Desfoque (opcional, padrão: 0). 4. **`color`:** Cor da sombra (opcional, padrão: `currentColor`). **Não possui `spread-radius` nem `inset`.** Assim como `box-shadow`, aceita **múltiplas sombras**, separadas por vírgula. #### Exemplos Explicados de `text-shadow` ```html
Texto Visível

``` --- ### 3. `filter: drop-shadow()`: A Sombra Inteligente #### O que significa? `drop-shadow()` é uma função da propriedade `filter` do CSS. A diferença crucial é que ela aplica a sombra ao desenho real do conteúdo do elemento, respeitando áreas transparentes. Se você tiver uma imagem PNG com fundo transparente, a sombra será exatamente no formato do objeto desenhado, não no retângulo da imagem. #### Para que serve? - **Imagens com Transparência:** É a maneira correta de adicionar sombra a um ícone, logo ou foto PNG que não é um quadrado. - **Elementos com `clip-path`:** Se você usou `clip-path` para cortar uma `div` em forma de estrela, `box-shadow` ainda faria uma sombra retangular. `drop-shadow()` fará uma sombra em forma de estrela. - **SVGs:** Funciona perfeitamente com elementos SVG inline, seguindo as formas vetoriais. - **Tooltips com "setinha" (CSS):** Se você cria tooltips com pseudo-elementos (`::before`, `::after`) para fazer um triângulo, `drop-shadow()` sombreia o conjunto (balão + seta) como um todo, sem sombras separadas. #### Sintaxe Detalhada Ao contrário das outras, a sintaxe é uma função: ```css filter: drop-shadow(offset-x offset-y blur-radius color); ``` - **`offset-x` (Obrigatório):** Deslocamento horizontal. - **`offset-y` (Obrigatório):** Deslocamento vertical. - **`blur-radius` (Opcional, padrão: 0):** Desfoque. - **`color` (Opcional, padrão: `currentColor`):** Cor da sombra. É obrigatório seguir esta ordem dentro dos parênteses. **Novamente, não há `spread-radius` nem `inset`.** Para múltiplas sombras, você usa múltiplas funções `drop-shadow()` separadas por espaço, dentro da string da propriedade `filter`. ```css filter: drop-shadow(2px 2px 4px red) drop-shadow(-2px -2px 4px blue); ``` **Cuidado:** A propriedade `filter` é um "canivete suíço" que aceita outras funções (como `blur()`, `brightness()`, etc.). Se você usar `drop-shadow()`, precisa garantir que não está sobrescrevendo outros filtros. Para múltiplos filtros, você os separa por espaço. #### Exemplos Explicados de `filter: drop-shadow()` ```html

box-shadow (na caixa)

drop-shadow (na imagem)

box-shadow na clip-path

drop-shadow na clip-path

Isso é um tooltip com drop-shadow!
``` --- ### Considerações Finais e Dicas de Performance 1. **Performance de `filter: drop-shadow()`:** Lembre-se, o `drop-shadow()` força o navegador a analisar a "máscara alfa" (transparência) do elemento, o que pode ser computacionalmente mais caro do que `box-shadow`. Use-o estrategicamente, evitando animar muitos elementos com esse filtro ao mesmo tempo. 2. **A Propriedade `filter` é "tudo ou nada" em animações:** Se você animar `filter` para mudar a sombra, o navegador pode ter que repintar a camada inteira do elemento. Para animações mais suaves, muitas vezes é melhor usar `box-shadow` (que tem a GPU acionada de forma mais otimizada) ou truques com pseudo-elementos. 3. **Combinação de Técnicas:** Nada impede de usar `box-shadow` para a elevação principal de um card e `filter: drop-shadow()` para a imagem dentro dele. Eles trabalham em camadas diferentes e podem coexistir. 4. **Compatibilidade:** Todas essas propriedades têm excelente suporte nos navegadores modernos. `text-shadow` e `box-shadow` são extremamente antigas (CSS 2/3). `filter` é mais recente, mas já é um padrão consolidado.
