Cores · CSS

1️⃣ Nomes de cores (palavras-chave)

Usando nomes pré-definidos como red, blue, green, tomato, etc. Existem mais de 140 nomes reconhecidos.

Exemplo do CSS

.cor {
color: red;
background-color: lightblue;
}

Exemplo do HTML

<p class="cor">Texto vermelho com fundo azul claro</p>

Demonstração

Texto vermelho com fundo azul claro (demonstração da cor)

2️⃣ Hexadecimal (hex)

Formato #RRGGBB ou #RGB (com ou sem transparência #RRGGBBAA).

Exemplo do CSS

.cor {
color: #ff5733; /* laranja avermelhado */
background: #0a0; /* equivalente a #00aa00 */
}

Exemplo do HTML

<p class="cor">Texto laranja com fundo verde</p>

Demonstração

Texto laranja com fundo verde

3️⃣ RGB / RGBA

Red, Green, Blue (0 a 255) e Alpha (0 a 1) para transparência.

Exemplo do CSS

.cor {
color: rgb(255, 87, 51);
background: rgba(0, 0, 0, 0.5); /* preto com 50% opacidade */
}

Atualmente também pode usar rgb(255 87 51 / 0.8).

Exemplo do HTML

<p class="cor">Texto com fundo semi-transparente</p>

Demonstração

Texto com fundo semi-transparente

4️⃣ HSL / HSLA

Hue (0-360), Saturation (0%-100%), Lightness (0%-100%), Alpha.

Exemplo do CSS

.cor {
color: hsl(12, 100%, 60%); /* mesmo laranja */
background: hsla(200, 80%, 50%, 0.3);
}

Muito útil para criar variações de uma mesma cor (ex: mais claro/escuro).

Exemplo do HTML

<p class="cor">Texto com fundo azul transparente</p>

Demonstração

Texto com fundo azul transparente

💡 Dicas legais

Use HSL para gerar paletas. Para transparência, prefira rgba() ou hsla(). CSS moderno suporta color-mix(). Use variáveis CSS para temas.

Exemplo do CSS

:root {
--primaria: #3498db;
}
button {
background: var(--primaria);
}

Exemplo do HTML

<button>Botão com cor primária</button>

Demonstração
