Selectores Personalizados

Perfeito, aluno! Vamos começar nossa aula sobre **Seletores Personalizados em CSS**. Pode se acomodar, pegar seu café e abrir o editor de código. Vou ser seu guia nessa jornada. A aula será dividida em módulos: definição, propósito e exemplos práticos de cada tipo. --- ### 📘 Módulo 1: Introdução aos Seletores Personalizados **Definição e Propósito:** Imagine que você está pintando uma casa. As tags HTML são os cômodos genéricos (quarto, sala). Mas e se você quiser pintar *apenas a parede da TV* na sala? Você precisa de um identificador único, um "nome" para ela. Os seletores personalizados servem exatamente para isso: aplicar estilo de forma **pontual e estratégica**, sem depender apenas das tags. Eles são a base para um CSS organizado e eficiente. Hoje veremos dois tipos principais: 1. **Seletor de ID (`#`)** : Um identificador **único e exclusivo**. 2. **Seletor de Classe (`.`)** : Um identificador **reutilizável e agrupável**. --- ### 🆔 Módulo 2: Seletor de ID (`#nome-do-id`) **O que é?** O ID é como o seu CPF. É único no documento HTML. Nenhum outro elemento pode ter o mesmo ID. Serve para identificar um elemento específico e estilizá-lo de forma exclusiva. **Para que serve?** - Estilizar um elemento que é a "estrela" da página, como o `header` principal ou o `footer`. - Criar âncoras para navegação interna na página. - Alvo para manipulação pesada com JavaScript (muitas vezes, buscar um único elemento). **Sintaxe no CSS:** `#nome-do-id { ... }` **Sintaxe no HTML:** `` **Exemplo Prático com Código:** Vamos criar um cabeçalho que será o único na página e um botão de ação especial. ```html Aula: Seletores ID e Classe

Minha Página Incrível

Este é o único cabeçalho principal.

Conteúdo normal da página...

``` **Resultado Esperado:** Um cabeçalho azul escuro exclusivo no topo e um botão vermelho centralizado que só aparece uma vez. --- ### 🏷️ Módulo 3: Seletor de Classe (`.nome-da-classe`) **O que é?** A Classe é como uma "crachá" ou "etiqueta" que você pode colar em quantos elementos quiser. É reutilizável. Serve para criar um padrão de estilo que será aplicado a vários elementos que compartilham a mesma função ou aparência. **Para que serve?** - Estilizar elementos que se repetem, como cards de produtos, itens de menu, etc. - Criar estilos temáticos (ex: `.destaque`, `.aviso`, `.sombra`). - Agrupar elementos sob uma mesma regra visual sem precisar repetir código CSS. **Sintaxe no CSS:** `.nome-da-classe { ... }` **Sintaxe no HTML:** `` **Exemplo Prático com Código:** Vamos criar um estilo para "cartões de produto" que se repetem. ```html Classes Reutilizáveis

O preço é verde e maior. --- ### 💡 Módulo 4: Regra de Ouro e Dicas do Professor **1. Mas e se eu quiser estilizar um elemento **apenas quando ele está dentro de outro**? Aqui entram os combinadores. --- #### 1. Seletor Descendente (espaço) **O que é?** Seleciona um elemento que é filho, neto, bisneto... de outro, em qualquer nível de hierarquia. **Para que serve?** Aplicar estilo a tags específicas que estão dentro de um container, sem afetar as mesmas tags fora dele. É o "pai de todos" da organização. **Sintaxe:** `pai descendente { ... }` **Exemplo:** Vamos estilizar todos os links (``) que estão DENTRO de um menu de navegação, mas não os links do rodapé. ```html
Home Sobre
Política de Privacidade
``` **Resultado:** Links do menu ficam brancos e sem sublinhado. O link do rodapé continua azul. --- #### 2. Seletor de Filho Direto (`>`) **O que é?** Mais rigoroso que o descendente. Seleciona apenas o elemento que é **filho imediato**, ou seja, no primeiro nível de hierarquia dentro do pai. **Para que serve?** Quando você quer estilizar apenas os itens de uma lista principal (`
  • `), e não os itens de uma sub-lista aninhada dentro dela. **Sintaxe:** `pai > filho-direto { ... }` **Exemplo:** Estrutura de menu com submenu. ```html
    • Home
    • Produtos
      • Livros
      • Ebooks
    • Contato
    ``` **Resultado:** Só "Home", "Produtos" e "Contato" ganham a linha vermelha. "Livros" e "Ebooks", por estarem mais profundos (são netos), não são afetados. --- #### 3. Seletor de Irmão Adjacente (`+`) **O que é?** Seleciona o irmão que está **IMEDIATAMENTE APÓS** um elemento específico. Apenas o primeiro irmão que aparece em seguida. **Para que serve?** Controle refinado de margens. Exemplo clássico: "Quero uma margem superior maior no parágrafo que vem logo depois de um título, mas não nos parágrafos seguintes." **Sintaxe:** `elemento-anterior + irmao-seguinte { ... }` **Exemplo:** Espaçamento inteligente entre título e parágrafo. ```html

    Título da Seção

    Este parágrafo é o primeiro após o título. Ganha estilo especial.

    Este é o segundo parágrafo. Não é adjacente ao título, então fica normal.

    Outro Título

    Uma div no meio.

    Este parágrafo NÃO é adjacente ao título (a div está no meio). Fica normal.

    ``` **Resultado:** Um subtítulo estiloso aparece logo abaixo do primeiro `

    `. Os outros parágrafos e o que tem uma `div` no meio não ganham o estilo. --- ### 🧰 Módulo 6: Seletores de Atributo – Estilo por Característica **O que são?** Permitem selecionar elementos com base na **presença de um atributo** ou no **valor específico desse atributo**. Extremamente útil para formulários e links. **Para que serve?** - Estilizar campos de formulário de um certo tipo (`type="text"`, `type="email"`, etc.). - Diferenciar links internos de externos (`href` que começa com "http"). - Estilizar elementos que tenham atributos especiais (`disabled`, `required`). **Sintaxes principais:** | Seletor | Significado | Exemplo | | :--- | :--- | :--- | | `[atributo]` | Tem o atributo, não importa o valor. | `[title]` (qualquer elemento com dica) | | `[atr="valor"]` | Atributo é exatamente igual. | `input[type="text"]` (campo de texto) | | `[atr^="valor"]` | Atributo **começa** com o valor. | `a[href^="https"]` (links seguros/externos) | | `[atr$="valor"]` | Atributo **termina** com o valor. | `a[href$=".pdf"]` (links para PDF) | | `[atr*="valor"]` | Atributo **contém** o valor. | `a[href*="google"]` (links com google no endereço) | **Exemplo Prático:** Vamos estilizar um formulário e links de forma inteligente. ```html




    Link Externo para Google

    Link Interno para Contato

    Baixar Manual (PDF) ``` **Resultado:** Um formulário com campos de texto azuis e botão verde. Links externos em vermelho, links internos normais e um link para PDF claramente identificado. --- ### 📝 Desafio Ninja (Para Casa) Crie uma página de portfólio simples onde: 1.
