Selectores Personalizados

id="" identificador unico ou individual

Tratamrnto no codigo HTML

Para usar selecror individual digitasse dentro da tag html que precisamos selecionar a paravra id="no,me-do-identificador",
exemplo: <p id="paragrafo-imprtante"> p-aragrafo com identificador</>

Tratamento no CSS

no CSS usamos o nome da tag + # + nome-do-identificador { estilizacao }
Exemplo: p#nomde-do-identificador {
text-align: center;
color: rede;
}

Nota Importante

nao pode usar mesmo nome de id para 2 elementos no mesmo documeno html

# em css significa id em html

p#nomde-do-id → significa apenas id do paragrafo como o nome mencionado #nomde-do-id → significa todos id do paragrafo como o nome mencionado
