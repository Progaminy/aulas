Tipografia

Tipografia é a arte e a técnica de organizar e dar forma às letras, palavras e blocos de texto, com o objetivo duplo de garantir boa legibilidade e transmitir uma atmosfera ou emoção específica na comunicação visual.

Categorias de fontrs

  • Serifadas (Serif) – Com pequenos "pés" nas extremidades. Exemplos: Times New Roman, Garamond, Georgia.
  • Sem Serifas (Sans Serif) – Sem os pés, traços limpos e retos. Exemplos: Helvetica, Arial, Open Sans.
  • Sem Serifas (Sans Serif) – Sem os pés, traços limpos e retos. Exemplos: Helvetica, Arial, Open Sans.
  • Manuscritas (Script) – Imitam caligrafia ou letra cursiva. Exemplos: Brush Script, Pacifico.
  • Monoespaçadas (Monospace) – Todas as letras ocupam a mesma largura. Exemplos: Courier New, Consolas.
  • Display / Decorativas – Feitas para chamar atenção em títulos e cartazes. Exemplos: Impact, fontes temáticas.

Fontes

  • font-family – Define a fonte
    • body {
    font-family: "Helvetica Neue", Arial, sans-serif;
    }

    colocasse 2 ou 3 combinacao para garantir a funcionalidade em divesros navegadores, para saber combinacoes de fonte vao para

    várias opções (fallbacks) – a última deve ser uma genérica (`serif`, `sans-serif`, `monospace`) - Nomes com espaços vão entre aspas

    fonte para Elementos HTML

    <style> h1, h2 {
    font-family: 'Times New Roman', Times, serif;
    }

    Nao pode espaco entre o numero e a unidade

  • font-weight – Espessura
    • <style> h1 { font-weight: lighter;} /* Fina */
    h2 { font-weight: normal; } /* 400 normal */
    b3 { font-weight: bold; } /* 700 */
    h4 { font-size: bolder;} /* grossa */
    h2 { font-weight: 100 - 300; } /* variacao de 100 a 200 */
    </style>

    Valores: 100 (thin), 200–`900` (black)

  • font-style – Estilo

    • Normal ou italico

    p { font-style: italic; }
    h1 { font-style: normal; }
  • shortthand font
    • <style> p {
    /* font-style → font-weigth → font-size → font-family font: italic bolder 4em 'work sans', sans-serif;
    }
    </style>
  • text-decoratio (decorar texto)
    • body { text-decoration: underline; /* sublinhado */ }
  • line-height – Entrelinha (fundamental para leitura)
    • <style> body {
    line-height: 1.5; /* sem unidade = múltiplo do tamanho da fonte */
    }
    </style>

    Ideal para textos longos: entre 1.4 e 1.6

  • letter-spacing – Entrelace/Kerning
    • <style> h1 { letter-spacing: 2px; } /* aumenta espaço entre letras */
    .uppercase { letter-spacing: 1px; } /* maiúsculas precisam mais */
    </style>
  • text-align – Alinhamento
    • p { text-align: left; } /* padrão */
    .center { text-align: center; }
    .justify { text-align: justify; } /* cuidado com "rios" brancos */

    Como importar fontes no CSS

  • Buscar fontes externos
    • body {
    font-family: 'Open Sans', sans-serif;
    }
    @import no CSS
    @import url('https://fonts.googleapis.com/css2?family=Roboto&display=swap');
  • @font-face – fonte local ou personalizada
    • @font-face {
    font-family: 'MinhaFonte';
    src: url('minha-fonte.woff2') format('woff2');
    font-weight: normal;
    font-style: normal;
    }

Boas práticas para web

Tabvela

| Prática | Por quê? | |---------|----------| | Use `rem` para `font-size` | Respeita as configurações de acessibilidade do usuário | | `line-height` sem unidade (`1.5`) | Mantém proporção ao tamanho da fonte | | Prefira fontes **sem serifa** para corpo de texto em telas | Melhor leiturabilidade em monitores | | Limite a **3 fontes** por projeto | Performance e coerência visual | | Use `font-display: swap` | Evita "flash de texto invisível" (FOIT) |

/* Exemplo de configuração base sólida */
html {
font-size: 100%; /* 16px por padrão */
} body {
font-family: system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif;
font-size: 1rem;
line-height: 1.5;
font-weight: 400;
color: #1a1a1a;
} h1, h2, h3 {
font-weight: 600;
line-height: 1.2;
letter-spacing: -0.02em; /* títulos levemente mais juntos */
}
