Tipografia

Tipografia é a arte e a técnica de organizar e dar forma às letras, palavras e blocos de texto, com o objetivo duplo de garantir boa legibilidade e transmitir uma atmosfera ou emoção específica na comunicação visual.

Categorias de fontes

  • Serifadas (Serif) – Com pequenos "pés" nas extremidades. Exemplos: Times New Roman, Garamond, Georgia.
  • Sem Serifas (Sans Serif) – Sem os pés, traços limpos e retos. Exemplos: Helvetica, Arial, Open Sans.
  • Manuscritas (Script) – Imitam caligrafia ou letra cursiva. Exemplos: Brush Script, Pacifico.
  • Monoespaçadas (Monospace) – Todas as letras ocupam a mesma largura. Exemplos: Courier New, Consolas.
  • Display / Decorativas – Feitas para chamar atenção em títulos e cartazes. Exemplos: Impact, fontes temáticas.

Fontes

  • font-family – Define a fonte
body { font-family: "Helvetica Neue", Arial, sans-serif; }

Colocam-se 2 ou 3 combinações para garantir a funcionalidade em diversos navegadores. Para saber combinações de fontes, visite:

🔗 CSS Web Safe Font Combinations

Várias opções (fallbacks) – a última deve ser uma genérica (serif, sans-serif, monospace) - Nomes com espaços vão entre aspas.

Fonte para Elementos HTML

<style> h1, h2 { font-family: 'Times New Roman', Times, serif; } </style>
  • font-size – Tamanho de fonte

Medidas Absolutas:

cm (centímetro)
mm (milímetro)
in (polegada)
px (pixel)
pt (ponto) – melhor para impressão no papel, Word usa pt
pc (paica) – melhor para impressão no papel

Medidas Relativas

rem (relativo ao html) – melhor para acessibilidade
em – relativo ao elemento pai
ex – altura do x
vw – largura da viewport
%

Medidas Recomendadas

em
px

Não pode haver espaço entre o número e a unidade.

  • font-weight – Espessura
<style> h1 { font-weight: lighter; } /* Fina */ h2 { font-weight: normal; } /* 400 normal */ h3 { font-weight: bold; } /* 700 */ h4 { font-weight: bolder; } /* grossa */ h2 { font-weight: 100; } /* variação de 100 a 900 */ </style>

Valores: 100 (thin), 200–900 (black)

  • font-style – Estilo

Normal ou itálico

p { font-style: italic; } h1 { font-style: normal; }
  • shorthand font
<style> p { /* font-style → font-weight → font-size → font-family */ font: italic bolder 4em 'Work Sans', sans-serif; } </style>
  • text-decoration (decorar texto)
body { text-decoration: underline; /* sublinhado */ }
  • line-height – Entrelinha (fundamental para leitura)
<style> body { line-height: 1.5; /* sem unidade = múltiplo do tamanho da fonte */ } </style>

Ideal para textos longos: entre 1.4 e 1.6

  • letter-spacing – Entrelace/Kerning
<style> h1 { letter-spacing: 2px; } /* aumenta espaço entre letras */ .uppercase { letter-spacing: 1px; } /* maiúsculas precisam mais */ </style>
  • text-align – Alinhamento
p { text-align: left; } /* padrão */ .center { text-align: center; } .justify { text-align: justify; } /* cuidado com "rios" brancos */

Como importar fontes no CSS

  • Buscar fontes externas

Exemplo de link no HTML:

<link href="https://fonts.googleapis.com/css2?family=Open+Sans:wght@400;700&display=swap" rel="stylesheet">
body { font-family: 'Open Sans', sans-serif; }

@import no CSS

@import url('https://fonts.googleapis.com/css2?family=Roboto&display=swap');
  • @font-face – fonte local ou personalizada
@font-face { font-family: 'MinhaFonte'; src: url('minha-fonte.woff2') format('woff2'); font-weight: normal; font-style: normal; }
