🎨 Corporar CSS

📌 In Line

Pode incorporar CSS em cada linha colocando dentro da tag iniciando com a palavra style=""

<p style="color: red;"> texto em vermelho </p>

O CSS in line tem prioridade sobre o CSS externo e interno

📄 CSS Interno ou Local

Pode incorporar CSS dentro da tag <head> usando a tag <style>

<head> <style> body { color: red; } </style> </head>

O CSS interno ou local tem prioridade sobre o CSS externo

🌐 CSS Externos

No cabeçalho crie um link:css

<link rel="stylesheet" href="CAMINHO_DA_PASTA/style.css">

Na pasta style.css coloque o código CSS

@charset "UTF-8"; * { margin: 0; padding: 0; box-sizing: border-box; -webkit-tap-highlight-color: transparent; } body { background: radial-gradient(circle at 20% 10%, #0a0c0f 0%, #020304 100%); font-family: 'Share Tech Mono', 'Courier New', monospace; color: #e0f0ff; min-height: 100vh; padding: 1.5rem 1.2rem 2.5rem; display: flex; flex-direction: column; align-items: center; justify-content: flex-start; position: relative; line-height: 1.5; -webkit-user-select: none; user-select: none; }
