⚡Atualização e Instalação

Para que o Termux saiba o que pode ser instalado e qual a versão mais recente disponível, ele precisa de uma lista. Essa lista é mantida nos servidores do Termux e é atualizada regularmente pelos desenvolvedores.

🔄 COMANDO: atualizar a lista de pacotes

pkg update

SIGNIFICA: "package update" — em português, "atualizar pacote" (mas aqui, atualiza a lista de pacotes).

FUNÇÃO: Sincroniza seu Termux com os servidores oficiais, baixando a lista mais recente de todos os softwares disponíveis.

O QUE FAZ:

  • Conecta-se ao repositório principal do Termux (ou ao espelho que você configurou via termux-change-repo).
  • Baixa arquivos de índice que contêm nomes, versões e descrições de todos os pacotes.

Atualiza o banco de dados interno do gerenciador apt.

NÃO INSTALA NADA: Este comando é totalmente seguro e não modifica nenhum programa no seu dispositivo. Ele só atualiza o "catálogo".

RELAÇÃO COM OUTROS: Este é o primeiro passo obrigatório. Sem executar pkg update antes, os comandos pkg upgrade (atualizar programas) e pkg install (instalar novos programas) podem falhar ou instalar versões antigas.

Exemplo prático do que acontece se você não fizer isso:

Imagine que foi lançada uma atualização de segurança para o Python. Se você não rodar pkg update primeiro, seu Termux ainda estará olhando para uma lista velha, onde essa atualização não existe. Ele não vai encontrá-la.

⬆️ COMANDO: atualizar os programas instalados

pkg upgrade

SIGNIFICA: "package upgrade" — em português, "atualizar pacote" (mas aqui, atualiza os programas instalados).

FUNÇÃO: Verifica quais programas instalados têm versões mais recentes disponíveis e os atualiza para essas versões.

O QUE FAZ:

  • Primeiro, verifica a lista de pacotes atualizada (que você obteve com pkg update) para ver se há versões mais recentes dos programas que você tem.
  • Se encontrar atualizações, baixa os arquivos necessários e instala as novas versões, substituindo as antigas.

IMPORTANTE: Este comando pode modificar ou substituir programas no seu dispositivo. Ele é seguro, mas é recomendado revisar as mudanças propostas antes de confirmar a atualização, especialmente se você tiver programas personalizados ou dependências específicas.

RELAÇÃO COM OUTROS: Este comando depende de pkg update para funcionar corretamente. Sem uma lista atualizada, ele pode não encontrar as atualizações disponíveis.

Exemplo prático do que acontece se você não fizer isso:

Se uma vulnerabilidade de segurança for corrigida em um programa que você usa, e você não rodar pkg upgrade, seu programa continuará vulnerável. Mesmo que você tenha a lista atualizada, se não fizer a atualização, estará exposto a riscos.

📋 Comando: Listando Pacotes Disponíveis

pkg list-all

SIGNIFICA: "package list-all" — em português, "listar todos os pacotes".

FUNÇÃO: Exibe uma lista completa de todos os pacotes disponíveis no catálogo que o pkg update baixou.

O QUE FAZ:

  • Lê o banco de dados de pacotes disponíveis.
  • Mostra na tela uma lista imensa (mais de 5000 itens) nome-do-pacote/versão arquitetura

Essa lista passará rapidamente pela tela (rolagem contínua).

NÃO INSTALA NADA: É apenas uma consulta ao catálogo.

RELAÇÃO COM OUTROS:

  • Depende do pkg update: Só mostra o que está no catálogo atualizado.
  • Precede buscas mais específicas: É útil para ver tudo, mas pouco prático para achar algo específico.
