🚀 Documentação de Pesquisa: Servidor SSH & Linux Proot no Termux

O Termux transforma qualquer dispositivo Android num ambiente Linux completo sem necessidade de root. Abaixo estão os comandos para configurar o armazenamento interno, servidor SSH e distribuições completas (Ubuntu/Debian) via proot-distro.

termux-cli — Configuração de Servidor & Proot 
# 1. Liberar Acesso ao Armazenamento Interno do Android
termux-setup-storage

# 2. Atualizar Repositórios e Instalar Pacotes Base
pkg update && pkg upgrade -y
pkg install python git openssh wget curl proot-distro -y

# 3. Iniciar Servidor OpenSSH no Termux (Porta Padrão: 8022)
sshd
whoami   # Mostra seu nome de usuário no Termux
passwd   # Define uma senha para acesso SSH remotamente

# 4. Instalar Distribuição Ubuntu completa dentro do Termux
proot-distro install ubuntu
proot-distro login ubuntu   # Entra no terminal Ubuntu completo!
