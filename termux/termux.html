📦 Gerenciadores de Pacotes: apk vs pkg vs apt (Atualizar Sistema)

O comando apk é o gerenciador de pacotes do Alpine Linux (muito usado no app iSH do iOS, containers Docker minimalistas e ambientes Alpine). Veja a comparação de comandos para atualizar sistemas (copie 1 a 1):

🏔️ Alpine Linux / iSH iOS (Comando APK):
apk update && apk upgrade
👉 Instalar pacote no Alpine: apk add python3 git bash curl

🚀 Passo a Passo: Ligar Servidor Python no Linux / Termux (Da Instalação até a URL)

Guia completo para instalar o Python, criar o projeto, ligar o servidor HTTP nativo e acessar a URL no celular ou computador (copie 1 a 1):

1. Atualizar gerenciador de pacotes (Termux):
pkg update && pkg upgrade -y
Ou no Ubuntu/Debian: sudo apt update && sudo apt upgrade -y
2. Instalar o Python 3 (Termux):
pkg install python -y
Ou no Ubuntu/Debian: sudo apt install python3 -y
3. Criar a pasta do projeto e entrar nela:
mkdir -p ~/servidor_python && cd ~/servidor_python
4. Criar o arquivo HTML base (index.html):
echo '<h1>Servidor Python Rodando no Linux!</h1>' > index.html
5. Ligar o servidor HTTP nativo do Python escutando na porta 8000 na Wi-Fi:
python -m http.server 8000 --bind 0.0.0.0
Deverá aparecer: Serving HTTP on 0.0.0.0 port 8000. Não feche este terminal!
6. Descobrir o endereço IP local do Linux/Termux (em outra aba/terminal):
ifconfig
Ou: ip a ou hostname -I. Anote o IPv4 (ex: 192.168.1.100 ou 10.0.0.15).
7. Liberar a porta 8000 no Firewall UFW (se for Ubuntu/Debian):
sudo ufw allow 8000/tcp
📱 8. URL para Acessar no Navegador de Qualquer Dispositivo na mesma Wi-Fi:
http://192.168.1.100:8000
9. Desligar o servidor no terminal: Pressione Ctrl + C na janela do terminal onde o servidor está ligado.
