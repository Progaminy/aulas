🌐 1. Fundamentos do PHP
O que é PHP?
PHP (Hypertext Preprocessor) é uma linguagem de script open-source para o lado do servidor (Server-Side), especialmente adequada para o desenvolvimento web e que pode ser embutida dentro do HTML.
index.php — Olá Mundo e Variáveis 
<?php
// Script Backend PHP Lendário
$titulo = "Pensador Sem Fronteiras";
$ano = 2026;
$ativo = true;

echo "<h1>⚡ Bem-vindo ao portal " . $titulo . " (" . $ano . ")</h1>";

if ($ativo) {
    echo "<p style='color:#00ffaa;'>🟢 Servidor PHP operacional em modo Lendário!</p>";
}
?>
📝 2. Receber dados de Formulários ($_POST)
Interação com o Utilizador
O PHP captura dados submetidos por formulários web através das superglobais `$_POST` e `$_GET` sanitizando dados contra ataques XSS.
login.php — Sanitização e Processamento 
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // Sanitizar input para evitar ataques XSS
    $usuario = htmlspecialchars(trim($_POST["usuario"]));
    $email = filter_var($_POST["email"], FILTER_SANITIZE_EMAIL);

    if (!empty($usuario) && filter_var($email, FILTER_VALIDATE_EMAIL)) {
        echo "<div class='sucesso'>✅ Login efetuado para: " . $usuario . "</div>";
    } else {
        echo "<div class='erro'>❌ Dados inválidos!</div>";
    }
}
?>
🗄️ 3. Conexão Segura com Banco de Dados (PDO)
Prepared Statements (Segurança)
Utilizar o PDO (PHP Data Objects) com *Prepared Statements* protege completamente a aplicação contra ataques de SQL Injection.
conexao.php — PDO MySQL 
<?php
$host = "localhost";
$db   = "pensador_db";
$user = "root";
$pass = "segredo123";

try {
    $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
    ]);
    
    // Consulta Segura com Prepared Statement
    $stmt = $pdo->prepare("SELECT id, nome, email FROM usuarios WHERE status = :status");
    $stmt->execute(['status' => 'ativo']);
    $usuarios = $stmt->fetchAll();
    
    foreach ($usuarios as $u) {
        echo "👤 " . $u['nome'] . " (" . $u['email'] . ")<br>";
    }
} catch (PDOException $e) {
    echo "❌ Erro na Conexão: " . $e->getMessage();
}
?>
