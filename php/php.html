🌐 1. Fundamentos & Como Executar/Rodar Códigos PHP
O que é PHP?
PHP (Hypertext Preprocessor) é uma linguagem de script open-source para o lado do servidor (Server-Side). O código PHP é executado no servidor e o resultado é enviado para o navegador do utilizador como HTML puro.
⚡ Como Rodar/Executar o PHP Passo a Passo (4 Métodos)
Para executar código PHP, você não pode simplesmente clicar com dois cliques num ficheiro .php. O PHP precisa de um servidor web ou do interpretador CLI. Escolha o método desejado abaixo (copie 1 a 1):
🚀 Método 1 (Mais Recomendado): Iniciar Servidor Web Embutido no VS Code:
Abra o terminal do VS Code (Ctrl + `), entre na pasta do projeto e inicie o servidor:
php -S localhost:8000
👉 Depois abra o navegador em: http://localhost:8000
🖥️ Método 2: Executar direto no Terminal (CLI sem navegador):
Executa o script PHP e mostra o resultado de texto direto na tela do terminal:
php index.php
🔍 Verificar se o PHP está instalado no seu computador:
php -v
🐧 Instalar PHP no Linux (Ubuntu / Kali / Debian):
sudo apt update && sudo apt install php -y
index.php — Olá Mundo e Variáveis 
<?php
// Script Backend PHP Lendário
$titulo = "Pensador Sem Fronteiras";
$ano = 2026;
$ativo = true;

echo "<h1>⚡ Bem-vindo ao portal " . $titulo . " (" . $ano . ")</h1>";

if ($ativo) {
    echo "<p style='color:#00ffaa;'>🟢 Servidor PHP operacional em modo Lendário!</p>";
}
?>
📦 1.1. Extensão `.php`, Dependências (Composer) & Estrutura Básica Automática
Extensão Oficial do Ficheiro
A extensão padrão para ficheiros de código PHP é .php (exemplo: index.php, api.php, conexao.php). Um ficheiro .php permite misturar estruturas HTML5 com blocos de código backend demarcados por <?php ... ?>.
Como Baixar Dependências no VS Code (Composer)
Assim como o Node.js utiliza o npm, o PHP utiliza o Composer para baixar e gerir pacotes/dependências. No terminal integrado do VS Code (Ctrl + `), utilize os comandos abaixo (copie 1 a 1):
📌 Inicializar projeto PHP e criar composer.json:
composer init
📌 Baixar uma dependência/pacote (ex: PHPMailer para enviar e-mails):
composer require phpmailer/phpmailer
📌 Instalar todas as dependências listadas no projeto:
composer install
Estrutura Básica Automática (Boilerplate PHP + HTML5)
No VS Code, assim como digita ! ou html:5 para gerar a estrutura base em HTML, para PHP basta digitar php + Tab para abrir as tags <?php ?>. Abaixo está o modelo de estrutura básica completa para arquivos .php:

📝 2. Receber dados de Formulários ($_POST)
Interação com o Utilizador
O PHP captura dados submetidos por formulários web através das superglobais `$_POST` e `$_GET` sanitizando dados contra ataques XSS.
login.php — Sanitização e Processamento 
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    // Sanitizar input para evitar ataques XSS
    $usuario = htmlspecialchars(trim($_POST["usuario"]));
    $email = filter_var($_POST["email"], FILTER_SANITIZE_EMAIL);

    if (!empty($usuario) && filter_var($email, FILTER_VALIDATE_EMAIL)) {
        echo "<div class='sucesso'>✅ Login efetuado para: " . $usuario . "</div>";
    } else {
        echo "<div class='erro'>❌ Dados inválidos!</div>";
    }
}
?>
🗄️ 3. Conexão Segura com Banco de Dados (PDO)
Prepared Statements (Segurança)
Utilizar o PDO (PHP Data Objects) com *Prepared Statements* protege completamente a aplicação contra ataques de SQL Injection.
conexao.php — PDO MySQL 
<?php
$host = "localhost";
$db   = "pensador_db";
$user = "root";
$pass = "segredo123";

try {
    $pdo = new PDO("mysql:host=$host;dbname=$db;charset=utf8mb4", $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
    ]);
    
    // Consulta Segura com Prepared Statement
    $stmt = $pdo->prepare("SELECT id, nome, email FROM usuarios WHERE status = :status");
    $stmt->execute(['status' => 'ativo']);
    $usuarios = $stmt->fetchAll();
    
    foreach ($usuarios as $u) {
        echo "👤 " . $u['nome'] . " (" . $u['email'] . ")<br>";
    }
?>
🗄️ 4.1. Consultas SQL Avançadas & Transações ACID
Modelagem, JOINs e Operações Atómicas
Consultas a banco de dados relacional exigem rigor contra inconsistências. O uso de JOINs permite relacionar dados de múltiplas tabelas, enquanto Transações (ACID) garantem que operações compostas (ex: transferência de saldo) sejam concluídas com sucesso total ou desfeitas com rollBack().
consultas_avancadas.php — JOINs e Transações Atómicas 
<?php
// 1. Consulta SQL Avançada com INNER JOIN, GROUP BY e ORDER BY
$sql = "SELECT u.id, u.nome, COUNT(p.id) AS total_postagens, MAX(p.criado_em) AS ultima_postagem
        FROM usuarios u
        INNER JOIN postagens p ON u.id = p.usuario_id
        WHERE u.status = :status
        GROUP BY u.id, u.nome
        HAVING total_postagens > 0
        ORDER BY total_postagens DESC
        LIMIT :limit OFFSET :offset";

$stmt = $pdo->prepare($sql);
$stmt->bindValue(':status', 'ativo', PDO::PARAM_STR);
$stmt->bindValue(':limit', 10, PDO::PARAM_INT);
$stmt->bindValue(':offset', 0, PDO::PARAM_INT);
$stmt->execute();
$relatorio = $stmt->fetchAll();

// 2. Transação Atómica Segura (Transferência de Saldo / Pontos)
try {
    $pdo->beginTransaction(); // Inicia transação segura

    // Subtrai da conta de origem
    $stmt1 = $pdo->prepare("UPDATE contas SET saldo = saldo - :valor WHERE id = :de");
    $stmt1->execute([':valor' => 100.00, ':de' => 1]);

    // Adiciona na conta de destino
    $stmt2 = $pdo->prepare("UPDATE contas SET saldo = saldo + :valor WHERE id = :para");
    $stmt2->execute([':valor' => 100.00, ':para' => 2]);

    $pdo->commit(); // Confirma alterações no Banco de Dados
    echo "✅ Transferência realizada com sucesso atómico!";
} catch (Exception $e) {
    $pdo->rollBack(); // Reverte todas as alterações em caso de erro!
    echo "❌ Transação cancelada: " . $e->getMessage();
}
?>
🔐 5. Gestão de Sessões (`session_start()`) & Cookies
Persistência de Estado no Servidor
Sessões mantêm o estado do utilizador entre diferentes requisições HTTP. É fundamental utilizar `session_regenerate_id(true)` após o login para prevenir ataques de *Session Fixation*.
sessao.php — Autenticação e Sessão Segura 
<?php
session_start();

// Simulação de login bem sucedido
$_SESSION['usuario_id'] = 42;
$_SESSION['usuario_nome'] = "Pensador";
$_SESSION['ip_remoto'] = $_SERVER['REMOTE_ADDR'];

// Regenera o ID de sessão para segurança
session_regenerate_id(true);

echo "🟢 Sessão iniciada para " . $_SESSION['usuario_nome'];
?>

Superglobais Internas da Linguagem

🧩 7. POO Avançada no PHP 8+ (Constructor Promotion & Enums)
Recursos Modernos do PHP 8.1+
O PHP moderno suporta promoção de propriedades no construtor, tipos de retorno estritos, interfaces, classes abstratas e enum para tipagem segura de constantes.
poo_moderno.php — PHP 8+ POO 
<?php
declare(strict_types=1);

enum StatusUsuario: string {
    case Ativo = 'ativo';
    case Inativo = 'inativo';
    case Pendente = 'pendente';
}

interface Autenticavel {
    public function autenticar(string $senha): bool;
}

class Usuario implements Autenticavel {
    // Constructor Property Promotion (PHP 8.0+)
    public function __construct(
        public int $id,
        public string $nome,
        public string $email,
        private string $hashSenha,
        public StatusUsuario $status = StatusUsuario::Ativo
    ) {}

    public function autenticar(string $senha): bool {
        return password_verify($senha, $self->hashSenha);
    }
}

// Instanciação limpa
$senhaHash = password_hash("minhasenha123", PASSWORD_ARGON2ID);
$user = new Usuario(1, "Pensador", "pensador@exemplo.com", $senhaHash);

echo "👤 Usuário: {$user->nome} | Status: {$user->status->value}";
?>
🌐 8. Construção de Endpoints API REST JSON
Backend para Single Page Applications & Mobile
Como estruturar um controlador de API que responde em formato JSON, gerencia códigos de status HTTP (200, 400, 404, 500) e lê payloads JSON recebidos no corpo da requisição.
api.php — Endpoint JSON RESTful 
<?php
header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');

$metodo = $_SERVER['REQUEST_METHOD'];

if ($metodo === 'GET') {
    $resposta = [
        'status' => 'sucesso',
        'mensagem' => 'API de Pesquisa PHP Ativa',
        'timestamp' => time(),
        'dados' => ['modulo' => 'PHP 8 Backend', 'autor' => 'Pensador Sem Fronteiras']
    ];
    http_response_code(200);
    echo json_encode($resposta, JSON_UNESCAPED_UNICODE | JSON_PRETTY_PRINT);
} elseif ($metodo === 'POST') {
    $rawInput = file_get_contents('php://input');
    $input = json_decode($rawInput, true);
    
    http_response_code(201);
    echo json_encode(['status' => 'criado', 'recebido' => $input]);
} else {
    http_response_code(405);
    echo json_encode(['erro' => 'Método Não Permitido']);
}
?>
