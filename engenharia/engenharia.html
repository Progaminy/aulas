DIAGRAMA 1 🏗️ Curva de Tensão vs Deformação ($\sigma - \epsilon$)

Fundamental para a **Engenharia Civil e Mecânica**: Como os materiais reais (ex: Aço Estrutural NBR 8800) reagem à tração antes de romperem:
📐 Dimensionamento Estrutural: Tensão Média & Módulo de Young
1. Tensão Normal ($\sigma$): $\sigma = \frac{F}{A}$, onde $F = 50.000\text{ N}$ e área $A = 100\text{ mm}^2 = 10^{-4}\text{ m}^2$.
2. Cálculo da Tensão: $\sigma = \frac{50000}{0,0001} = 500.000.000\text{ Pa} = 500\text{ MPa}$.
3. Lei de Hooke ($\epsilon$): Para o Aço ($E = 200\text{ GPa} = 200.000\text{ MPa}$): $\epsilon = \frac{\sigma}{E} = \frac{500}{200000} = 0,0025\text{ (0,25\%)}$.
sigma = F / A => 50kN / 100mm2 = 500 MPa | epsilon = 500 / 200000 = 0.0025

DIAGRAMA 2 🖥️ Arquitetura de Sistemas Profissionais de Software

Como um sistema web industrial é estruturado de ponta a ponta (Load Balancer, Backend e Base de Dados):
📐 Regras de Dimensionamento de Servidores & Alta Disponibilidade
1. Taxa de Requisições por Segundo (RPS): $RPS = \frac{\text{Usuários Ativos} \times \text{Req/min}}{60} = \frac{10.000 \times 6}{60} = 1.000\text{ RPS}$.
RPS = (10000 * 6) / 60 = 1000 RPS | Load Balancer -> 2x Worker Nodes

DIAGRAMA 3 📻 Engenharia Eletrônica: Amplificadores Operacionais (Op-Amp) & Filtros

Na **Engenharia Eletrônica**, o **Amplificador Operacional (Op-Amp LM741 / LM358)** é o bloco fundamental para amplificação de sinais analógicos de sensores (temperatura, pressão, áudio) antes da conversão para o mundo digital (ADC):
📐 Cálculo de Ganho de Tensão em Amplificadores Eletrônicos
1. Ganho de Tensão Inversor ($A_v$): $A_v = -\frac{R_2}{R_1} = -\frac{100.000}{10.000} = -10\text{ vezes}$.
2. Tensão de Saída para $V_{in} = 0,5\text{V}$: $V_{out} = A_v \cdot V_{in} = -10 \cdot 0,5\text{V} = -5,00\text{ Volts}$.
Av = - (R2 / R1) = - (100k / 10k) = -10 | V_out = -10 * 0.5V = -5.00V
