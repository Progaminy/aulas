⚡ Como Instalar o Python no Windows pelo Terminal (Passo a Passo)
Se o comando curl der erro de URL ou decimal, utilize o PowerShell no terminal para baixar e instalar o Python silenciosamente com o PATH configurado automaticamente (copie 1 a 1):
📌 Passo 1: Baixar o instalador oficial do Python 3.12 via PowerShell:
powershell -command "Invoke-WebRequest -Uri https://www.python.org/ftp/python/3.12.4/python-3.12.4-amd64.exe -OutFile python-installer.exe"
📌 Passo 2: Executar instalação silenciosa e configurar PATH automaticamente:
python-installer.exe /quiet InstallAllUsers=1 PrependPath=1
📌 Passo 3: Verificar se o Python foi instalado com sucesso:
python --version
📌 Passo 4: Apagar o instalador baixado para liberar espaço:
del python-installer.exe

📁 4. Ficheiros Físicos & Exceções (`try / except`)
Persistência de Dados e Robustez
O bloco `with open(...)` garante o encerramento automático de ficheiros após leitura ou escrita, prevenindo fugas de memória. O tratamento de exceções impede que erros de execução parem o programa.
ficheiros.py — Escrita e Tratamento de Exceção 
import os

# Escrita segura em arquivo com gerenciador de contexto (with)
def salvar_relatorio(filename, dados):
    try:
        with open(filename, 'w', encoding='utf-8') as f:
            f.write(dados)
        print(f"✅ Ficheiro '{filename}' salvo com sucesso!")
    except IOError as err:
        print(f"❌ Erro ao gravar ficheiro: {err}")

# Leitura e verificação de existência
salvar_relatorio("pesquisa_pensador.txt", "Documento de Pesquisa Avançada em Python")

if os.path.exists("pesquisa_pensador.txt"):
    with open("pesquisa_pensador.txt", "r", encoding="utf-8") as f:
        conteudo = f.read()
        print(f"📖 Conteúdo Lido: {conteudo}")

🗄️ 5.1. Consultas a Bancos de Dados (SQLite3) & Filtros JSON
Persistência Relacional com Consultas Parametrizadas
Python disponibiliza o motor de banco de dados SQLite3 integrado. É fundamental utilizar tuplas no execute() para consultas parametrizadas seguras contra injeção SQL, permitindo consultas avançadas com WHERE, LIKE e ORDER BY.
consultas_sqlite.py — CRUD & Consultas Parametrizadas 
import sqlite3

# Conectar/Criar banco de dados local em memória ou arquivo
conn = sqlite3.connect("pesquisa_pensador.db")
cursor = conn.cursor()

# 1. Criar Tabela
cursor.execute("""
CREATE TABLE IF NOT EXISTS modulos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    tecnologia TEXT NOT NULL,
    nivel INTEGER NOT NULL,
    concluido INTEGER DEFAULT 0
)
""")

# 2. Inserir Dados Parametrizados (Segurança Total)
cursor.execute("INSERT INTO modulos (tecnologia, nivel) VALUES (?, ?)", ("Python", 1))
cursor.execute("INSERT INTO modulos (tecnologia, nivel) VALUES (?, ?)", ("PHP", 1))
conn.commit()

# 3. Executar Consulta SQL com Filtros e Ordenação
busca = "%Py%"
cursor.execute("SELECT id, tecnologia, nivel FROM modulos WHERE tecnologia LIKE ? ORDER BY nivel DESC", (busca,))
resultados = cursor.fetchall()

print("🔍 Resultados da Consulta SQL:")
for linha in resultados:
    print(f" -> ID: {linha[0]} | Tecnologia: {linha[1]} | Nível: {linha[2]}")

conn.close()
🧩 6. Orientação a Objetos Avançada (POO & Dunder Methods)
Encapsulamento, Herança e Polimorfismo
A POO em Python permite estruturar sistemas através de classes. Métodos mágicos (Dunder Methods como __init__, __str__, __repr__ e __call__) personalizam a interação dos objetos com a linguagem.
poo_avancado.py — Classes e Herança 
class Servidor:
    def __init__(self, ip: str, porta: int):
        self._ip = ip          # Atributo protegido
        self.__porta = porta   # Atributo privado
        self.ativo = True

    def __str__(self):
        return f"Servidor({self._ip}:{self.__porta}) [{'Online' if self.ativo else 'Offline'}]"

    def status(self):
        return f"📡 IP: {self._ip} | Porta: {self.__porta}"

class ServidorWeb(Servidor):
    def __init__(self, ip: str, porta: int = 80, ssl: bool = True):
        super().__init__(ip, porta)
        self.ssl = ssl

    def testar_conexao(self):
        protocolo = "HTTPS" if self.ssl else "HTTP"
        print(f"🔗 Conectando via {protocolo} ao servidor {self._ip}...")

# Instanciação e Execução
srv = ServidorWeb("192.168.1.100", 443, ssl=True)
print(srv)
srv.testar_conexao()
⚡ 7. Concorrência Assíncrona (`asyncio` & Sockets)
Execução Não-Bloqueante de Alta Performance
O módulo asyncio possibilita a execução concorrente de tarefas I/O bound utilizando corrotinas async e await, ideal para rastreadores web, scanners de rede e microserviços.
async_scanner.py — Scanner de Portas Assíncrono 
import asyncio

async def verificar_porta(host, porta):
    try:
        reader, writer = await asyncio.wait_for(
            asyncio.open_connection(host, porta), timeout=1.0
        )
        print(f"✅ Porta {porta} ABERTA em {host}")
        writer.close()
        await writer.wait_closed()
    except (asyncio.TimeoutError, ConnectionRefusedError, OSError):
        pass # Porta fechada ou sem resposta

async def main():
    target = "scanme.nmap.org"
    portas = [21, 22, 80, 443, 8080]
    print(f"🔍 Escaneando {target} assincronamente...")
    tarefas = [verificar_porta(target, p) for p in portas]
    await asyncio.gather(*tarefas)

# Rodar o Event Loop Assíncrono
asyncio.run(main())
