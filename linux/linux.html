MÓDULO 1

📁 Arquitetura do Sistema de Arquivos (FHS Linux)

No Linux, tudo é um arquivo. Entenda a árvore de diretórios padrão (Filesystem Hierarchy Standard):
📌 Diretório Raiz `/` (A base de todo o sistema de arquivos):
ls -ld /
📌 `/bin` e `/sbin` (Executáveis essenciais dos usuários e administradores):
ls -la /bin
📌 `/etc` (Arquivos de configuração do sistema e serviços):
ls -la /etc
📌 `/home` e `/root` (Diretórios pessoais dos usuários comuns e do superusuário root):
ls -la /home
📌 `/var` (Arquivos variáveis: logs, bancos de dados, filas e caches):
ls -la /var/log
📌 `/tmp` (Arquivos temporários apagados na reinicialização):
ls -la /tmp
📌 `/proc` e `/sys` (Sistemas de arquivos virtuais com dados do Kernel e Hardware):
cat /proc/version
MÓDULO 2

🧭 Navegação, Criação & Manipulação de Arquivos e Pastas

Comandos essenciais para transitar pelo terminal, criar, mover, copiar e remover arquivos:
📌 Exibir o caminho da pasta atual (Print Working Directory):
pwd
📌 Listar arquivos com detalhes, tamanhos legíveis e ocultos:
ls -lah
📌 Criar pasta com subpastas de forma aninhada (`-p`):
mkdir -p projeto/src/componentes
📌 Criar um novo arquivo vazio ou atualizar a data de alteração:
touch index.html script.js estilo.css
📌 Copiar arquivo ou pasta inteira recursivamente (`-r`):
cp -rv projeto/ projeto_backup/
📌 Mover ou renomear arquivos e pastas:
mv antigo.txt novo.txt
📌 Deletar pasta e todo o seu conteúdo sem pedir confirmação (`-rf`):
rm -rf pasta_antiga
📌 Exibir a árvore de diretórios em formato gráfico:
tree -L 2
MÓDULO 3

📝 Leitura, Criação & Edição de Arquivos de Texto

Métodos para visualizar, inspecionar logs e editar códigos diretamente no terminal Linux:
📌 Exibir todo o conteúdo de um arquivo no terminal:
cat arquivo.txt
📌 Ver as primeiras 20 linhas de um arquivo grande:
head -n 20 arquivo.txt
📌 Acompanhar um arquivo de LOG em tempo real (`tail -f`):
tail -f /var/log/syslog
📌 Ler arquivo grande com navegação paginada (Sair com `Q`):
less /var/log/auth.log
📌 Criar arquivo escrevendo o conteúdo direto no terminal (`>`):
echo 'servidor_ligado = True' > config.py
📌 Adicionar uma nova linha ao final sem apagar o existente (`>>`):
echo 'porta = 8000' >> config.py
📌 Abrir o editor de texto amigável Nano:
nano arquivo.txt
MÓDULO 4

🔐 Permissões (CHMOD/CHOWN), Usuários & Segurança

Gerenciamento de permissões rwx (leitura, escrita, execução), usuários e privilégios sudo:
📌 Dar permissão de execução a um script shell (`+x`):
chmod +x script.sh
📌 Permissão total para o dono, leitura/execução para os outros (`755`):
chmod 755 script.sh
📌 Permissão privada restrita apenas para o dono (`600` para chaves SSH/Senhas):
chmod 600 ~/.ssh/id_rsa
📌 Alterar o dono e grupo de uma pasta recursivamente (`chown`):
sudo chown -R www-data:www-data /var/www/html
📌 Criar novo usuário com pasta home própria:
sudo useradd -m -s /bin/bash dev_user
📌 Configurar ou alterar a senha de um usuário:
sudo passwd dev_user
📌 Adicionar usuário ao grupo de Administradores (`sudo`):
sudo usermod -aG sudo dev_user
MÓDULO 5

⚡ Gerenciamento de Processos, CPU, RAM & Tarefas

Acompanhe o consumo de hardware, gerencie processos e execute tarefas em background:
📌 Listar todos os processos rodando no sistema com detalhes (`ps aux`):
ps aux
📌 Monitorar a memória RAM em formato legível (MB/GB):
free -h
📌 Abrir o gerenciador de tarefas interativo Htop:
htop
📌 Encontrar o número PID de um processo pelo nome:
pgrep -l python
📌 Matar forçadamente um processo pelo seu número PID (`kill -9`):
kill -9 1234
📌 Matar todos os processos de um determinado programa:
pkill -f python
📌 Executar um script em segundo plano contínuo (`nohup &`):
nohup python3 app.py &
MÓDULO 6

💾 Discos, Partições, Montagem & Armazenamento

Inspeção de espaço livre, partições conectadas e comandos de montagem de drives:
📌 Ver espaço livre e ocupado em todas as partições (`df -h`):
df -h
📌 Calcular o tamanho ocupado por cada pasta no diretório atual:
du -sh *
📌 Listar blocos de discos e partições físicas (`lsblk`):
lsblk -f
📌 Montar uma partição pendrive/disco externo em uma pasta (`mount`):
sudo mount /dev/sdb1 /mnt
📌 Desmontar uma partição com segurança antes de desconectar:
sudo umount /mnt
MÓDULO 7

🌐 Redes, IP, Portas, SSH & Transferência Remota

Configuração de interfaces de rede, portas abertas, acesso SSH e download de dados:
📌 Descobrir o endereço IP local e dados das placas de rede:
ip a
📌 Listar todas as portas abertas e serviços escutando (`ss -tuln`):
ss -tuln
📌 Testar a conectividade com um servidor ou site (`ping`):
ping -c 4 google.com
📌 Fazer o cabeçalho HTTP de resposta de um servidor web:
curl -I https://google.com
📌 Conectar a um servidor Linux remoto via SSH:
ssh usuario@192.168.1.100 -p 22
📌 Copiar arquivos para um servidor remoto com segurança (`scp`):
scp -r projeto/ usuario@192.168.1.100:/var/www/
MÓDULO 8

🔍 Pesquisa Avançada, Filtros (Grep/Find) & Regex

Localize arquivos no sistema e busque por textos específicos dentro de milhares de linhas:
📌 Procurar texto dentro de todos os arquivos recursivamente com número da linha (`grep -rn`):
grep -rn "senha" /etc/
📌 Encontrar todos os arquivos com extensão `.py` a partir do diretório atual:
find . -name "*.py"
📌 Encontrar arquivos maiores que 100 MB para liberar espaço:
find / -type f -size +100M 2>/dev/null
📌 Substituir todas as ocorrências de uma palavra em um arquivo (`sed -i`):
sed -i 's/porta=80/porta=8080/g' config.txt
MÓDULO 9

📦 Compactação, Arquivação TAR.GZ & Backups

Crie pacotes compactados para backup e transporte de arquivos pesados:
📌 Compactar uma pasta inteira no formato `.tar.gz`:
tar -czvf backup_site.tar.gz /var/www/html
📌 Descompactar um arquivo `.tar.gz`:
tar -xzvf backup_site.tar.gz
📌 Criar um arquivo zip comum:
zip -r projeto.zip projeto/
📌 Extrair arquivo `.zip`:
unzip projeto.zip
MÓDULO 10

⚙️ Gerenciamento de Serviços (Systemd & Journalctl)

Controle a inicialização, paragem, reinício e verificação de status de serviços no Linux:
📌 Verificar o status de um serviço (ex: Nginx / Apache):
systemctl status nginx
📌 Iniciar um serviço parado:
sudo systemctl start nginx
📌 Reiniciar um serviço após alterar configurações:
sudo systemctl restart nginx
📌 Habilitar o serviço para iniciar automaticamente ao ligar o PC (`enable`):
sudo systemctl enable nginx
📌 Ver os logs ao vivo de um serviço específico (`journalctl -u -f`):
journalctl -u nginx -f
MÓDULO 11

📦 Gerenciadores de Pacotes (APT, PKG, APK, DNF)

Comandos para instalar programas nas principais distribuições Linux:
🐧 Ubuntu / Debian / Kali Linux (APT):
sudo apt update && sudo apt install -y python3 git curl nginx
📱 Termux no Android (PKG):
pkg update && pkg install python git nodejs -y
⛰️ Alpine Linux (APK):
apk update && apk add python3 git bash
🎩 Fedora / RHEL / CentOS (DNF):
sudo dnf install -y python3 git nginx
MÓDULO 12

🚀 Prática Guiada: Subir um Servidor Web Python do Zero

Tutorial completo para colocar um site no ar pelo terminal Linux e acessar pelo navegador da rede Wi-Fi:
1. Criar a pasta do servidor web e entrar nela:
mkdir -p ~/meu_site && cd ~/meu_site
2. Criar a página HTML de boas-vindas:
echo '<h1 style="color:cyan;text-align:center">Servidor Linux Ativo!</h1>' > index.html
3. Ligar o servidor HTTP Python na porta 8000 escutando a rede Wi-Fi:
python3 -m http.server 8000 --bind 0.0.0.0
4. Descobrir o seu IP local para acessar no celular (ex: 192.168.1.100):
hostname -I
📱 5. URL Final para abrir no Navegador:
http://192.168.1.100:8000
