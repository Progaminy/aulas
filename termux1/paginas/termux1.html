Comandos Basicos das ferramentas básicas do sistema.

  1. Comando: Verificar Usuario do terminal

    2. whoami

    Explicação do comando

    O comando whoami pergunta ao sistema: "Qual é o nome do usuário atual?" O Termux responde com um identificador interno do Android.
    Não é o nome do usuário do sistema Linux tradicional, mas sim um ID específico do ambiente Termux.
    📌 Para que serve whoami?
    Saber qual usuário está controlando o terminal
    📌 Útil quando você tiver vários usuários ou permissões diferentes

  2. Comando: Verificar diretório atual (mostrar caminho)

    3. pwd

    Explicação do comando

    O comando pwd significa "print working directory", ou seja, "imprimir diretório de trabalho". Ele mostra o caminho completo do diretório atual em que você está no terminal.
    📌 Para que serve pwd?
    Saber em qual diretório você está trabalhando
    📌 Útil para navegar e organizar arquivos

  3. Comando: Listar arquivos e pastas

    4. ls

    Explicação do comando

    O comando ls significa "list", ou seja, "listar". Ele mostra a lista de arquivos e pastas no diretório atual.
    📌 Para que serve ls?
    Visualizar o conteúdo de um diretório
    📌 Útil para navegar e encontrar arquivos

  4. Comando: Obter informações sobre um arquivo ou pasta (listar detalhadamente)

    5. ls -l

    Explicação do comando

    O comando ls -l mostra uma lista detalhada dos arquivos e pastas no diretório atual, incluindo permissões, proprietário, tamanho e data de modificação.
    📌 Para que serve ls -l?
    Obter informações detalhadas sobre arquivos e pastas
    📌 Útil para entender as propriedades dos arquivos

  5. Comando: Limpar a tela do terminal

    6. clear

    Explicação do comando

    O comando clear serve para limpar a tela do terminal. Ele remove todo o texto visível, os comandos antigos e suas saídas, deixando a tela completamente em branco. Seu único objetivo é ajudar na organização visual. Ele não apaga arquivos, não desfaz ações, não fecha nada. Só limpa a poluição visual da tela.
    📌 Para que serve clear?
    Limpar a tela do terminal
    📌 Útil para organizar a visualização do terminal

  6. Comando: Mudar de diretório

    7. cd

    Explicação do comando

    O comando cd significa "change directory", ou seja, "mudar de diretório". Ele permite que você navegue entre as pastas do sistema.
    📌 Para que serve cd?
    Navegar entre diretórios
    📌 Útil para acessar diferentes partes do sistema de arquivos

    cd (entrando em uma pasta específica)

    Para entrar em uma pasta específica, você pode usar o comando cd seguido do nome da pasta. Por exemplo, se você quiser entrar na pasta "Documentos", basta digitar:

    cd Documentos

    Isso mudará o diretório atual para a pasta "Documentos", desde que ela exista no diretório atual. Se a pasta estiver em outro local, você pode fornecer o caminho completo ou relativo para ela.

    Este comando tem duas partes: o comando em si e o destino. O destino pode ser um caminho ou um atalho especial. Para esta primeira aula de navegação, usaremos um atalho fundamental: .. (dois pontos finais).

    cd ..

    Explicação do comando cd ..

    O comando cd .. é usado para subir um nível na hierarquia de diretórios. O .. significa "o diretório acima deste" ou "a pasta pai". É o que contém a pasta onde você está agora.
    📌 Para que serve cd ..?
    Subir um nível na hierarquia de diretórios
    📌 Útil para navegar para pastas superiores

  7. Comando: Voltar para o diretório inicial

    8. cd ~

    Explicação do comando cd ~

    O comando cd ~ é usado para voltar para o diretório inicial do usuário. O símbolo ~ representa o diretório home do usuário, que é onde você começa quando abre o terminal.
    📌 Para que serve cd ~?
    Voltar para o diretório inicial do usuário
    📌 Útil para acessar rapidamente o diretório home

  8. Comando: Criar uma nova pasta

    9. mkdir nome_da_pasta

    Explicação do comando

    O comando mkdir significa "make directory", ou seja, "criar diretório". Ele permite que você crie uma nova pasta no diretório atual.
    📌 Para que serve mkdir?
    Criar novas pastas
    📌 Útil para organizar arquivos e diretórios
