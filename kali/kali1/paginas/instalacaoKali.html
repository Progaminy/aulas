Guia interativo · Do ISO ao primeiro login

Baseado na tua jornada real — sem atalhos, cada etapa explicada.

1 O ponto de partida

📦 kali-linux-2026.1-installer-amd64.iso já está na tua pasta Downloads. Não é .zip, é um ISO legítimo. A confusão inicial foi desfeita: o arquivo não precisa ser extraído — apenas montado na máquina virtual.

🔐 Hash SHA256 oficial (confirmado na página):
271477ad6ea2676c7346576971b9acc2d32fabd9c2bbaf0e6302397626149306

2 VirtualBox + nova VM

Oracle VirtualBox já instalado. Criar máquina com os valores refinados durante a conversa:

🧠 RAM: 4869 MB
⚙️ CPU: 4 núcleos
💾 Disco: 30 GB (dinâmico)

📌 Localização: Disco E: (restavam 48 GB livres). Pasta sugerida: E:\VMs\Kali2026

📌 Versão: Ubuntu (64-bit) — compatível com Kali.

📌 EFI: Desmarcado (boot legacy simples).

3 Montar o ISO

Configurações → Armazenamento → Controladora IDE → CD vazio → escolher arquivo de disco:

kali-linux-2026.1-installer-amd64.iso

Iniciar a VM. Assim que surgir o menu preto, selecionar Graphical install.

4 Diálogo de instalação

A sequência exata que seguiste (e as escolhas feitas):

  • 🌐 Idioma: Português de Portugal
  • 🌍 País: Portugal (Moçambique não listado; fuso ajustado depois)
  • ⌨️ Teclado: Português (Portugal) — QWERTY com ç
  • 🔌 Rede: DHCP automático (NAT VirtualBox funciona perfeitamente)
  • 🏷️ Hostname: kali (ou kali-vm)
  • 📛 Domínio: (vazio)
  • 👤 Utilizador: kali · Senha: pensador123 (letras+números, sem barras)
  • 🕒 Fuso horário: Lisboa (UTC+0, depois ajustar para Africa/Maputo)

5 Particionamento (sem LVM)

Guiado - usar todo o disco · disco /dev/sda (30 GB).

Esquema: Todos os arquivos em uma partição. Nada de LVM — decisão consciente para primeira experiência.

Finalizar o particionamento e escrever as alterações no disco → Sim

Motivo: LVM traria flexibilidade, mas aumenta complexidade na recuperação. "Talvez quando estiver mais maduro".

6 Seleção de software

Na tela dos quadrados (marcar/desmarcar), mantiveste:

✅ Xfce (desktop) ✅ collection of tools ✅ top10 ✅ default

GNOME/KDE desmarcados. A instalação prosseguiu (sistema base + pacotes).

7 Finalização & GRUB

Quando surgir Instalar o GRUB no /dev/sda → Sim. Após reiniciar, remover o ISO da unidade óptica (VirtualBox → Dispositivos → Remover disco).

Primeiro login: kali / pensador123.

8 Ajuste fuso horário (Maputo)

Depois do login, abrir terminal e executar:

sudo timedatectl set-timezone Africa/Maputo

Assim o relógio fica certo para Moçambique (UTC+2).

9 Programar no Kali · VS Code

O Kali pode ser usado para programar (APK, scripts, etc). O VS Code não vem incluso, mas instala-se facilmente:

sudo apt update && sudo apt install code -y

Também podes ter outra VM com Ubuntu para desenvolvimento geral. Cada VM é independente.
