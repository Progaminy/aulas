📘 O que é Linux? E o Kali?

Linux é um sistema operativo (como Windows), mas gratuito e de código aberto. Existem muitas versões chamadas distribuições.

🐉 Kali Linux é uma distribuição especializada em segurança digital e testes de penetração. Vem com centenas de ferramentas prontas.

Neste guia, vais aprender a instalar o Kali dentro de uma máquina virtual — um computador simulado dentro do teu Windows.

Antes de começar, precisas de dois ficheiros:

📦 Baixar VirtualBox 🌐 Baixar Kali ISO

💡 Dica O ficheiro do Kali termina em .iso — é uma imagem de disco. Não precisas de extrair!

1 Criar a máquina virtual

Abre o Oracle VirtualBox e clica em "Novo".

  • 📛 Nome: Kali Linux 2026.1
  • 🖥️ Tipo: Linux · Versão: Ubuntu (64-bit)
  • 🧠 RAM: 4869 MB (ou 4096 MB se tiveres 8 GB no PC)
  • 💾 Disco: 30 GB (dinâmico) — guarda em E: se o C: estiver cheio
  • ⚙️ CPU: 4 núcleos (metade dos teus núcleos reais)

⚠️ EFI Deixa desmarcado (boot legacy é mais simples).

2 Montar o ISO do Kali

Com a VM selecionada, vai a Configurações → Armazenamento.

Clica no ícone do CD vazio e escolhe "Escolher um ficheiro de disco...".

kali-linux-2026.1-installer-amd64.iso

Depois clica em Iniciar (seta verde).

3 Instalação (Graphical Install)

No menu preto, escolhe Graphical install e segue:

  • 🌐 Idioma: Português (Portugal)
  • 🌍 País: Portugal (Moçambique não está na lista)
  • ⌨️ Teclado: Português (Portugal)
  • 🔌 Rede: DHCP automático
  • 🏷️ Hostname: kali
  • 📛 Domínio: (deixar vazio)
  • 👤 Utilizador: kali · Senha: pensador123
  • 🕒 Fuso: Lisboa (depois ajustamos para Maputo)

4 Particionamento (simples)

Escolhe Guiado - usar todo o disco e seleciona o disco /dev/sda.

Esquema: Todos os ficheiros numa partição.

Finalizar particionamento → Sim

Sem LVM — mais fácil para recuperar se algo correr mal.

5 Seleção de software

Na lista de quadrados, mantém marcado:

✅ Xfce ✅ tools (coleção) ✅ top10 ✅ default

GNOME e KDE desmarcados. Continua.

6 GRUB e primeiro login

Quando perguntar "Instalar o GRUB no /dev/sda?" → Sim.

Após reiniciar, faz login com:

kali / pensador123

⚙️ Configurações iniciais úteis

Assim que entrares no Kali, executa estes passos:

1. Ajustar fuso horário (Maputo)

sudo timedatectl set-timezone Africa/Maputo
sudo = executa como administrador. timedatectl = comando que controla data/hora. set-timezone = define o fuso.

2. Atualizar o sistema

sudo apt update && sudo apt upgrade -y
apt update = atualiza a lista de pacotes disponíveis. apt upgrade -y = instala todas as atualizações automaticamente. O && executa o segundo comando só se o primeiro der certo.

3. Instalar o VS Code (opcional)

sudo apt install code -y
apt install code = instala o Visual Studio Code. -y = responde "sim" automaticamente a perguntas.

📟 Primeiros comandos (e o que fazem)

Experimenta estes no terminal para te familiarizares:

pwd
pwd = mostra a pasta onde estás agora.
ls
ls = lista ficheiros e pastas do diretório atual.
cd /home/kali
cd = muda de diretório. Aqui vai para a pasta pessoal do utilizador "kali".
whoami
whoami = mostra com que utilizador estás ligado.
