Abrir Aquivos - Linux

Principais, dependendo do tipo de arquivo:

Para conteudo de texto:

- **`cat arquivo.txt`** → Exibe todo o conteúdo de uma vez na tela. - **`less arquivo.txt`** → Abre o arquivo permitindo rolar a página (use `q` para sair). - **`head arquivo.txt`** → Mostra apenas as 10 primeiras linhas. - **`tail arquivo.txt`** → Mostra apenas as 10 últimas linhas. - **`nano arquivo.txt`** → Abre no editor de texto simples do terminal. ## Para abrir com **programa específico**: - **`xdg-open arquivo.pdf`** → Abre com o programa padrão do sistema (PDF, imagem, vídeo, etc.). - **`libreoffice documento.docx`** → Abre no LibreOffice. - **`firefox index.html`** → Abre um arquivo HTML no Firefox. ## Exemplo prático: ```bash cd Documentos # entra na pasta Documentos ls # lista o que tem dentro cat notas.txt # vê o conteúdo do arquivo notas.txt xdg-open imagem.jpg # abre a imagem no visualizador padrão ``` ## Dica útil: - **`file nome_do_arquivo`** → Descobre que tipo de arquivo é antes de tentar abrir. Qual tipo de arquivo você está tentando abrir? Posso dar o comando exato para ele.
