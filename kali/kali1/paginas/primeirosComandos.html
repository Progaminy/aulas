🐉 Primeiros Comandos & Permissões no Kali

🔄 1. Atualização Completa de Sistema (APT)
terminal — Atualizar Sistema 
# Atualizar lista de repositórios e atualizar pacotes instalados
sudo apt update && sudo apt upgrade -y

# Atualização completa de distribuição (dist-upgrade)
sudo apt dist-upgrade -y
🔐 2. Permissões de Ficheiros (chmod & chown)
terminal — Conceder Execução e Trocar Dono 
# Dar permissão de execução a um script (.sh ou binário)
chmod +x meu_script.sh

# Dar permissão total de leitura, escrita e execução (755)
chmod 755 meu_script.sh

# Alterar o dono do arquivo para o usuário atual
sudo chown $USER:$USER arquivo.txt
👑 3. Elevação de Privilégios (Sudo & Root)
terminal — Comandos de Superusuário 
# Executar um único comando como administrador (root)
sudo apt install nmap

# Alternar para a sessão root definitiva
sudo -i

# Sair da sessão root
exit
