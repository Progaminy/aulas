🪟 Comandos Windows (CMD & PowerShell)

Guia Completo: Navegação de Pastas, Discos, Área de Trabalho & VS Code

📂 1. Entrar, Sair e Criar Pastas (Navegação de Diretórios)
Navegar entre pastas no Windows é feito com o comando cd (Change Directory). Aprenda os principais comandos para entrar, voltar e criar diretórios no terminal.
CMD / PowerShell — Navegação e Criação de Pastas 
# 1. Entrar em uma pasta (ex: pasta 'Projetos')
cd Projetos

# 2. Entrar em subpastas em um único comando
cd Projetos\Web\MeusSites

# 3. Voltar para a pasta anterior (subir 1 nível)
cd ..

# 4. Voltar 2 níveis de pasta de uma vez
cd ..\..

# 5. Voltar diretamente para a raiz do disco (ex: C:\)
cd \

# 6. Criar uma nova pasta
mkdir MinhaNovaPasta

# 7. Apagar uma pasta vazia
rmdir MinhaNovaPasta

# 8. Apagar uma pasta e TODAS as suas subpastas/arquivos sem pedir confirmação
rmdir /s /q MinhaPastaAntiga

# 9. Ver a árvore gráfica de estrutura das pastas
tree /f
🖥️ 2. Comandos Essenciais do Terminal Windows
Comandos utilitários para listar arquivos, limpar a tela e consultar informações do sistema.
CMD / PowerShell — Comandos Básicos de Sistema 
# 1. Listar todos os arquivos e pastas no diretório atual
dir

# 2. Listar SOMENTE pastas (diretórios)
dir /ad

# 3. Ver o caminho completo da pasta atual
cd

# 4. Limpar a tela do terminal
cls

# 5. Ver o endereço de IP e informações de rede
ipconfig

# 6. Exibir informações detalhadas sobre a máquina e sistema
systeminfo
💽 3. Como Alternar Entre Discos (C:, D:, E:)
No Windows, cada disco ou partição possui uma letra identificadora seguida de dois pontos (ex: C:, D:, E:).

⚠️ Atenção: Para trocar de disco no Windows, você NÃO usa o comando cd. Você deve digitar diretamente a letra do disco seguida de dois pontos e pressionar Enter.
CMD / PowerShell — Alternando entre Discos 
# Para entrar no Disco D: (segundo disco ou HD externo):
D:

# Para voltar ao Disco C: (disco principal do sistema):
C:

# Para entrar no Disco E: (Pendrive ou disco secundário):
E:

# Depois de entrar no disco desejado, use cd para navegar nas pastas:
D:
cd Projetos\MinhaAplicacao
🖥️ 4. Como Entrar na Área de Trabalho (Desktop)
A Área de Trabalho fica localizada dentro da pasta do seu perfil de usuário:
CMD / PowerShell — Navegando para o Desktop 
# Opção A: Se você já estiver na sua pasta de usuário (C:\Users\SeuNome):
cd Desktop

# Opção B: Atalho direto no CMD de qualquer lugar do sistema:
cd %USERPROFILE%\Desktop

# Opção C: Atalho direto no PowerShell de qualquer lugar:
cd $env:USERPROFILE\Desktop

# Opção D: Especificando o caminho manual completo:
cd C:\Users\SeuNomeDeUsuario\Desktop
📄 5. Ler, Copiar, Mover, Renomear & Processos
Comandos para manipular arquivos e gerenciar programas no Windows.
CMD / PowerShell — Manipulação de Arquivos e Processos 
# 1. Exibir o conteúdo de um arquivo de texto no terminal
type notas.txt

# 2. Abrir um arquivo no Bloco de Notas gráfico
notepad notas.txt

# 3. Copiar um arquivo para outra pasta ou nome
copy arquivo.txt backup_arquivo.txt

# 4. Mover um arquivo para outra pasta
move arquivo.txt C:\Users\%USERNAME%\Documents\

# 5. Renomear um arquivo ou pasta
ren arquivo_antigo.txt arquivo_novo.txt

# 6. Apagar um arquivo
del arquivo_inutil.txt

# 7. Listar todos os processos em execução no Windows
tasklist

# 8. Encerrar um processo travado por nome (ex: Chrome)
taskkill /F /IM chrome.exe
💎 6. Como Abrir o VS Code a Partir do Terminal
Abra qualquer pasta ou projeto diretamente no Visual Studio Code:
CMD / PowerShell — Abrindo o VS Code 
# 1. Abrir a pasta ATUAL inteira no VS Code:
code .

# 2. Entrar na Área de Trabalho e abrir no VS Code:
cd %USERPROFILE%\Desktop
code .

# 3. Abrir um arquivo específico diretamente no editor:
code index.html

# 4. Abrir o VS Code em uma nova janela independente:
code -n .
