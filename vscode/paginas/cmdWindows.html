🪟 Comandos Windows (CMD & PowerShell)

Guia Completo: Navegação de Discos, Área de Trabalho & VS Code

🖥️ 1. Comandos Essenciais do Terminal Windows
O Prompt de Comando (CMD) e o PowerShell são os terminais nativos do sistema operacional Windows para execução de comandos e automação.
CMD / PowerShell — Comandos Básicos de Sistema 
# 1. Listar arquivos e pastas no diretório atual
dir

# 2. Ver o caminho completo da pasta atual
cd

# 3. Criar uma nova pasta
mkdir MinhaNovaPasta

# 4. Limpar o histórico da tela do terminal
cls

# 5. Ver o endereço de IP e informações de rede
ipconfig

# 6. Exibir informações completas sobre o computador
systeminfo
💽 2. Como Alternar Entre Discos (C:, D:, E:)
No Windows, cada disco ou partição possui uma letra identificadora seguida de dois pontos (ex: C:, D:, E:).

⚠️ Atenção: Para trocar de disco no Windows, você NÃO usa o comando cd. Você deve digitar diretamente a letra do disco seguida de dois pontos e pressionar Enter.
CMD / PowerShell — Alternando entre Discos 
# Para entrar no Disco D: (segundo disco ou HD externo):
D:

# Para voltar ao Disco C: (disco principal do sistema):
C:

# Para entrar no Disco E: (Pendrive ou disco secundário):
E:

# Depois de entrar no disco desejado, use o comando cd para navegar nas pastas:
D:
cd Projetos\MinhaAplicacao
🖥️ 3. Como Entrar na Área de Trabalho (Desktop)
A Área de Trabalho fica localizada dentro da pasta do seu perfil de usuário. Você pode entrar nela de duas formas rápidas:
CMD / PowerShell — Navegando para o Desktop 
# Opção A: Se você já estiver na sua pasta de usuário (C:\Users\SeuNome):
cd Desktop

# Opção B: Atalho direto no CMD de qualquer lugar do sistema:
cd %USERPROFILE%\Desktop

# Opção C: Atalho direto no PowerShell de qualquer lugar:
cd $env:USERPROFILE\Desktop

# Opção D: Especificando o caminho manual completo:
cd C:\Users\SeuNomeDeUsuario\Desktop
💎 4. Como Abrir o VS Code a Partir do Terminal
O executável do Visual Studio Code inclui o atalho CLI code. Com ele, você pode abrir qualquer pasta ou arquivo diretamente no VS Code com um único comando!
CMD / PowerShell — Abrindo o VS Code 
# 1. Abrir a pasta ATUAL inteira no VS Code:
code .

# 2. Abrir a pasta da Área de Trabalho no VS Code:
cd %USERPROFILE%\Desktop
code .

# 3. Abrir um arquivo específico diretamente no editor:
code index.html

# 4. Abrir o VS Code em uma nova janela independente:
code -n .

# 💡 Dica: Se o comando 'code' não for reconhecido:
# Abra o VS Code manualmente -> Pressione Ctrl+Shift+P -> Digite "Shell Command: Install 'code' command in PATH".
