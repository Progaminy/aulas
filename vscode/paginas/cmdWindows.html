🪟 Comandos Windows (CMD & PowerShell)

Cada comando tem o seu botão de cópia individual exato (1 por 1)

📂 1. Entrar, Sair e Criar Pastas (Comando por Comando)
Clique no botão 📋 Copiar ao lado de qualquer comando individual para copiar apenas aquele comando para a área de transferência:
📌 Entrar em uma pasta (ex: pasta 'Projetos'):
cd Projetos
📌 Entrar direto em subpastas aninhadas:
cd Projetos\Web\MeusSites
📌 Voltar para a pasta anterior (subir 1 nível):
cd ..
📌 Voltar 2 níveis de pasta de uma só vez:
cd ..\..
📌 Voltar diretamente para a raiz do disco (C:\):
cd \
📌 Criar uma nova pasta:
mkdir MinhaNovaPasta
📌 Apagar uma pasta vazia:
rmdir MinhaNovaPasta
📌 Apagar pasta e todo seu conteúdo forçadamente sem confirmação:
rmdir /s /q MinhaPastaAntiga
📌 Exibir árvore de diretórios e arquivos:
tree /f
🖥️ 2. Comandos Básicos de Sistema (Comando por Comando)
📌 Listar arquivos e pastas no diretório atual:
dir
📌 Listar APENAS pastas (diretórios):
dir /ad
📌 Ver o caminho completo da pasta atual:
cd
📌 Limpar a tela do terminal (CMD):
cls
📌 Limpar a tela do terminal (PowerShell):
Clear-Host
📌 Ver endereço IP e dados de rede:
ipconfig
📌 Exibir informações do sistema e hardware:
systeminfo
📝 2.1. Guia Completo: Como Criar Arquivos no Windows (CMD & PowerShell)
Existem vários métodos para criar arquivos de texto, código HTML, Python ou arquivos de teste no terminal Windows. Cada método abaixo possui o seu botão de cópia individual exato:
📌 1. Criar arquivo de texto 100% vazio de 0 bytes (CMD):
type nul > meu_arquivo.txt
📌 2. Criar arquivo com 1 linha em branco (CMD):
echo. > meu_arquivo.txt
📌 3. Criar arquivo já escrevendo um texto inicial (CMD):
echo "Conteúdo Inicial do Arquivo" > meu_arquivo.txt
📌 4. Adicionar novo texto ao FINAL de arquivo existente (CMD):
echo "Segunda Linha de Texto" >> meu_arquivo.txt
📌 5. Criar arquivo limpo via cópia de dispositivo nulo (CMD):
copy nul meu_arquivo.txt
📌 6. Criar arquivo de tamanho fixo em bytes (ex: 1 MB = 1048576 bytes) (CMD):
fsutil file createnew teste_1mb.txt 1048576
📌 7. Criar arquivo novo com comando nativo (PowerShell):
New-Item -Path . -Name "meu_arquivo.txt" -ItemType "File"
📌 8. Forçar criação de arquivo sobrescrevendo se existir (PowerShell):
New-Item -Path . -Name "novo.html" -ItemType "File" -Force
📌 9. Criar arquivo e definir conteúdo de texto (PowerShell):
Set-Content -Path "meu_arquivo.txt" -Value "Olá PowerShell"
📌 10. Adicionar nova linha no final do arquivo (PowerShell):
Add-Content -Path "meu_arquivo.txt" -Value "Nova linha adicionada"
📌 11. Criar arquivo especificando saída Out-File (PowerShell):
Out-File -FilePath "meu_arquivo.txt" -InputObject "Texto de Teste"
📌 12. Criar e abrir o arquivo no Bloco de Notas para edição (CMD/PowerShell):
notepad meu_arquivo.txt
🗑️ 2.2. Como Apagar Arquivos no Windows (CMD & PowerShell)
📌 Apagar um arquivo específico (CMD):
del meu_arquivo.txt
📌 Forçar exclusão silenciosa de arquivo sem pedir confirmação (CMD):
del /f /q meu_arquivo.txt
📌 Apagar todos os arquivos .txt da pasta atual (CMD):
del *.txt
📌 Apagar um arquivo (PowerShell):
Remove-Item meu_arquivo.txt

🖥️ 4. Entrar na Área de Trabalho (Desktop)
📌 Se você já estiver na sua pasta de usuário (C:\Users\SeuNome):
cd Desktop
📌 Atalho direto no CMD de qualquer lugar do sistema:
cd %USERPROFILE%\Desktop
📌 Atalho direto no PowerShell de qualquer lugar do sistema:
cd $env:USERPROFILE\Desktop
📄 5. Manipulação de Arquivos e Processos
📌 Exibir conteúdo de um arquivo no terminal:
type notas.txt
📌 Abrir arquivo no Bloco de Notas:
notepad notas.txt
📌 Copiar um arquivo:
copy arquivo.txt backup.txt
📌 Mover um arquivo para outra pasta:
move arquivo.txt %USERPROFILE%\Documents\
📌 Renomear um arquivo ou pasta:
ren antigo.txt novo.txt
📌 Apagar um arquivo:

📌 Listar processos em execução:
tasklist
📌 Encerrar um programa travado pelo nome:
taskkill /F /IM chrome.exe
💎 6. Abrir o VS Code pelo Terminal
📌 Abrir a pasta ATUAL inteira no VS Code:
code .
📌 Abrir um arquivo específico diretamente no editor:
code index.html
📌 Abrir o VS Code em nova janela independente:
code -n .
🌐 Abrir Links, URLs e Sites no Navegador pelo Terminal
Se digitar diretamente https://... no terminal do Windows, receberá a mensagem de erro "'https:' não é reconhecido como um comando interno...". Para abrir qualquer site ou link do GitHub Pages pelo terminal, utilize o comando start (CMD) ou Start-Process (PowerShell):
📌 Abrir site do GitHub Pages no Navegador Padrão (CMD):
start https://progaminy.github.io/aulas/index.html
📌 Abrir site no Navegador Padrão (PowerShell):
Start-Process "https://progaminy.github.io/aulas/index.html"
📌 Forçar abertura de um site especificamente no Google Chrome (CMD):
start chrome https://progaminy.github.io/aulas/index.html
💻 Comandos para Ver Informações do Sistema & Hardware
Comandos essenciais do Terminal do Windows para inspecionar a versão do SO, memória RAM, processador, discos rígidos e nome da máquina (copie 1 a 1):
📌 Exibir relatório completo do sistema (Versão, RAM, CPU, BIOS, Rede e Atualizações):
systeminfo
📌 Filtrar apenas Nome do Windows, Versão e Arquitetura (64-bit / 32-bit):
systeminfo | findstr /B /C:"OS Name" /C:"OS Version" /C:"System Type"
📌 Abrir janela gráfica com a versão exata e compilação do Windows:
winver
📌 Exibir o nome do computador na rede:
hostname
📌 Ver modelo e número de núcleos do Processador (CPU):
wmic cpu get name, NumberOfCores, MaxClockSpeed
📌 Ver capacidade e velocidade dos pentes de memória RAM:
wmic memorychip get Capacity, Speed, Manufacturer
📌 Ver modelo e tamanho dos discos rígidos / SSDs instalados:
wmic diskdrive get Model, Size, MediaType
📌 Abrir ferramenta de diagnóstico do DirectX (Placa de Vídeo e Áudio):
dxdiag
🚀 Comandos para Iniciar / Ligar um Servidor Web Local
Comandos para ligar servidores web de desenvolvimento no Terminal do Windows (PHP, Python, Node.js, Live-Server e Apache). Entre na pasta do seu projeto e execute (copie 1 a 1):
📌 Ligar Servidor Web Embutido do PHP (Acessar em http://localhost:8000):
php -S localhost:8000
📌 Ligar Servidor HTTP Embutido do Python 3 (Acessar em http://localhost:8000):
python -m http.server 8000
📌 Ligar Servidor Estático Rápido via Node.js (npx http-server):
npx http-server -p 8000
📌 Ligar Servidor Live-Server (Recarregamento Automático ao Salvar HTML/CSS/JS):
npx live-server
📌 Ligar Servidor de Desenvolvimento em Projetos (Vite / React / Next.js / Node):
npm run dev
📌 Iniciar Serviço do Servidor Apache no Linux / WSL / Termux:
sudo service apache2 start
📌 Iniciar Serviço do Servidor Nginx no Linux / WSL / Termux:
sudo service nginx start
📶 Comandos para Ligar, Desligar & Gerir Redes Wi-Fi
Comandos nativos do Windows (CMD e PowerShell como Administrador) para ativar a placa Wi-Fi, conectar a redes salvas, listar conexões disponíveis e descobrir senhas armazenadas (copie 1 a 1):
📌 Ligar / Ativar a placa de rede Wi-Fi do computador (CMD / Admin):
netsh interface set interface "Wi-Fi" admin=enabled
📌 Desligar / Desativar a placa de rede Wi-Fi do computador (CMD / Admin):
netsh interface set interface "Wi-Fi" admin=disabled
📌 Listar todas as redes Wi-Fi disponíveis ao redor:
netsh wlan show networks
📌 Listar todas as redes Wi-Fi salvas neste computador:
netsh wlan show profiles
📌 Conectar-se a uma rede Wi-Fi salva:
netsh wlan connect name="NomeDaSuaRede"
📌 Desconectar da rede Wi-Fi atual:
netsh wlan disconnect
📌 Revelar a senha salva em texto puro de uma rede Wi-Fi:
netsh wlan show profile name="NomeDaSuaRede" key=clear
📌 Ligar / Ativar placa Wi-Fi no PowerShell (Como Administrador):
Enable-NetAdapter -Name "Wi-Fi"
🖥️ Abrir Janelas de Configurações de Wi-Fi pelo Terminal
Atalhos nativos para abrir diretamente as páginas de rede do Windows sem precisar navegar pelos menus visuais (copie 1 a 1):
📌 Abrir página de Configurações de Wi-Fi do Windows 10/11:
start ms-settings:network-wifi
📌 Abrir pop-up/painel lateral de redes Wi-Fi disponíveis para conexão:
explorer ms-availablenetworks:
📌 Abrir o Centro de Rede e Compartilhamento clássico:
control.exe /name Microsoft.NetworkAndSharingCenter
🔄 Como Atualizar Programas & Sistema no Windows pelo Terminal
No Windows, o equivalente ao apt upgrade do Linux é o gerenciador nativo Winget. Use os comandos abaixo para atualizar todos os seus programas (VS Code, Python, Chrome, Git) e o próprio sistema Windows (copie 1 a 1):
🚀 Atualizar TODOS os programas e aplicativos instalados no Windows de uma só vez:
winget upgrade --all
📌 Listar quais programas instalados têm atualizações pendentes:
winget upgrade
📌 Abrir a janela do Windows Update nas Configurações:
start ms-settings:windowsupdate
📌 Iniciar varredura/escaneamento de atualizações do sistema Windows 10/11:
UsoClient StartScan
📌 Forçar detecção de atualizações do sistema:
wuauclt /detectnow
📌 Programar reinicialização do computador em 30 segundos:
shutdown /r /t 30
🐍 Baixar e Instalar o Python Direto pelo Terminal (Sem Navegador)
Se o comando curl der erro de URL ou decimal, utilize o PowerShell pelo terminal para baixar e instalar o Python silenciosamente com o PATH configurado automaticamente (copie 1 a 1):
📌 Passo 1: Baixar o instalador oficial do Python 3.12 via PowerShell:
powershell -command "Invoke-WebRequest -Uri https://www.python.org/ftp/python/3.12.4/python-3.12.4-amd64.exe -OutFile python-installer.exe"
📌 Passo 2: Executar instalação silenciosa e adicionar ao PATH automaticamente:
python-installer.exe /quiet InstallAllUsers=1 PrependPath=1
📌 Passo 3: Verificar se o Python foi instalado com sucesso:
python --version
📌 Passo 4: Apagar o arquivo instalador baixado para liberar espaço:
del python-installer.exe
⚡ Servidores Web em Python no Windows (Flask & FastAPI)
Comandos para instalar e rodar servidores web modernos em Python (copie 1 a 1):
📌 Instalar o micro-framework Flask:
pip install flask
📌 Instalar FastAPI e servidor de alta performance Uvicorn:
pip install fastapi uvicorn
📌 Ligar servidor FastAPI (Acessar em http://localhost:8000 e docs em /docs):
uvicorn main:app --reload --host 0.0.0.0 --port 8000
📌 Ligar servidor Flask:
python servidor.py
⚠️ Solução: "'pip' não é reconhecido como um comando interno..."
Se o Windows exibir o erro "'pip' não é reconhecido...", significa que o PIP não foi adicionado ao PATH do Windows. Utilize as soluções abaixo para rodar e corrigir imediatamente (copie 1 a 1):
🚀 Solução 1 (Instantânea): Usar o prefixo 'python -m pip' (Funciona SEMPRE sem mexer no PATH):
python -m pip install flask
📌 Forçar o Python a instalar/reinstalar o PIP nativo:
python -m ensurepip --upgrade
📌 Atualizar o PIP para a versão mais recente:
python -m pip install --upgrade pip
📌 Adicionar a pasta do PIP (Scripts) ao PATH do Windows via PowerShell:
powershell -command "[Environment]::SetEnvironmentVariable('Path', $env:Path + ';C:\Users\' + $env:USERNAME + '\AppData\Local\Programs\Python\Python312\Scripts', 'User')"
