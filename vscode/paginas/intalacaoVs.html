💎 Instalação do VS Code & Code-OSS

🌐 Método 1: Instalar VS Code Oficial (Microsoft)
terminal — Instalação via Repositório Microsoft 
# Adicionar a chave GPG da Microsoft
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg

# Adicionar repositório oficial
sudo sh -c 'echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" > /etc/apt/sources.list.d/vscode.list'

# Instalar VS Code
sudo apt update && sudo apt install code -y
🐉 Método 2: Instalar Code-OSS no Debian / Kali

O code-oss é a versão 100% open-source do Visual Studio Code fornecida diretamente pelos repositórios do Debian e Kali Linux.

terminal — Instalação Code-OSS 
# Atualizar lista e instalar code-oss nativo
sudo apt update
sudo apt install code-oss -y

# Executar o editor
code-oss
🔌 Instalar Extensões do VS Code via Linha de Comando
terminal — CLI Extension Installer 
# Instalar extensão de Python
code --install-extension ms-python.python

# Instalar extensão de PHP
code --install-extension bmewburn.vscode-intelephense-client

# Instalar extensão Prettier
code --install-extension esbenp.prettier-vscode
