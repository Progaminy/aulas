📦 Instalação (VS code)

Instalação - Baixar e Instalar VS code · Configurações Essenciais

# Baixar VS Code no site oficial:
https://code.visualstudio.com/

# Instalar via terminal (Linux/WSL):
sudo apt update && sudo apt install code

# Configurações recomendadas:
# Editor: Font Family 'Fira Code', Ligatures ativadas
# Tema: Dark+ ou One Dark Pro

⚙️ Dicas de Configurações Essenciais: Auto Save, Format on Save, e extensões como Prettier, Live Server. Ajuste o terminal integrado.

⚡ Productividade - Encapsulamento de texto em tag

Productividade — Encapsulamento de texto em tag: Selecione o texto e utilize Emmet (atalho padrão: Ctrl+Shift+P → Wrap with Abbreviation). Ou instale extensões como Text Power Tools. Visual Studio Code permite agilidade extrema.

Exemplo: selecione "meu texto" e digite "h1" + Tab → <h1>meu texto</h1>

Atalhos úteis:
- HTML: div>ul>li*3
- Encapsulamento: selecione e Ctrl+Shift+P -> "Emmet: Wrap with Abbreviation"
- Multi-cursor: Alt+Click

💡 Produtividade extra: atalhos como Ctrl+D selecionar ocorrências, Ctrl+Shift+L todas ocorrências. Use snippets personalizados para acelerar fluxo.
