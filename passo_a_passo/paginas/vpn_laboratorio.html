🧪 VPN LABORATÓRIO — ENCAPSULAMENTO

Laboratório Completo: Namespaces Isolados, Cabo Virtual veth, Túnel SOCKS5/SSH, NFTables & Tcpdump

🌐 1. Namespace Isolado 🔗 2. Cabo Virtual veth 🔑 3. Túnel SOCKS5 / SSH 🛡️ 4. Firewall NFTables & Tcpdump
PARTE 1

🛠️ Preparação & Confirmação de Ferramentas

Validar se o WARP está ativo e se as ferramentas de rede (`ip`, `ssh`, `sshd`, `nft`, `tcpdump`) estão instaladas:
1. Confirmar estado do WARP (esperado: warp=on):
warp-cli connect; curl -s https://www.cloudflare.com/cdn-cgi/trace | grep '^warp='
2. Confirmar presença das ferramentas essenciais:
command -v ip; command -v ssh; command -v sshd; command -v nft; command -v tcpdump
3. Instalar e ativar OpenSSH Server se faltar o sshd:
sudo apt install -y openssh-server && sudo systemctl enable --now ssh.socket
PARTE 2

🧹 Limpar Experiência Anterior

Eliminar namespaces, interfaces veth antigas, sockets SSH residuais e desativar o encaminhamento IP:
1. Remover namespace e link veth antigo:
sudo ip netns del laboratorio-vpn 2>/dev/null || true; sudo ip link del veth-host 2>/dev/null || true
2. Encerrar túnel SSH antigo e apagar o socket:
ssh -S /tmp/laboratorio-socks.sock -O exit psf@127.0.0.1 2>/dev/null || true; rm -f /tmp/laboratorio-socks.sock
3. Garantir que o encaminhamento IP está desativado:
sudo sysctl -w net.ipv4.ip_forward=0
PARTE 3

🌐 Criar a Rede Isolada (Namespace + Cabo veth)

Construir o namespace `laboratorio-vpn`, interligar o computador hospedeiro com o laboratório usando cabo virtual veth e atribuir os IPs `10.200.0.1` e `10.200.0.2`:
1. Criar o namespace e ativar a interface de loopback:
sudo ip netns add laboratorio-vpn && sudo ip netns exec laboratorio-vpn ip link set lo up
2. Criar o cabo virtual veth e mover a ponta veth-lab para o namespace:
sudo ip link add veth-host type veth peer name veth-lab; sudo ip link set veth-lab netns laboratorio-vpn
3. Configurar IP 10.200.0.1/24 no hospedeiro (veth-host):
sudo ip addr add 10.200.0.1/24 dev veth-host && sudo ip link set veth-host up
4. Configurar IP 10.200.0.2/24 no laboratório (veth-lab) e rota padrão:
sudo ip netns exec laboratorio-vpn ip addr add 10.200.0.2/24 dev veth-lab; sudo ip netns exec laboratorio-vpn ip link set veth-lab up; sudo ip netns exec laboratorio-vpn ip route add default via 10.200.0.1
5. Testar comunicação interna (ping 10.200.0.1):
sudo ip netns exec laboratorio-vpn ping -c 3 10.200.0.1
PARTE 4 & 5

🔒 Provar Sem Internet Direta & Criar Túnel SOCKS5 (Porta 1081)

Provar que o laboratório não tem internet direta e criar o proxy SOCKS5 na porta `10.200.0.1:1081` via SSH:
1. Provar que internet direta falha dentro do laboratório:
sudo ip netns exec laboratorio-vpn curl --connect-timeout 5 https://icanhazip.com
2. Criar o proxy SOCKS5 dinâmico SSH na porta 1081:
ssh -fNM -S /tmp/laboratorio-socks.sock -D 10.200.0.1:1081 -o ExitOnForwardFailure=yes psf@127.0.0.1
3. Confirmar que a porta 1081 está escutando:
sudo ss -ltnp | grep ':1081'
PARTE 6 & 7

🛡️ Restringir a Porta 1081 no NFTables & Prova Final

Configurar o firewall NFTables dentro do laboratório para bloquar tudo e permitir exclusivamente a porta TCP 1081:
1. Criar tabela e regras NFTables de bloqueio total (Policy Drop):
sudo ip netns exec laboratorio-vpn nft add table inet laboratorio; sudo ip netns exec laboratorio-vpn nft 'add chain inet laboratorio output { type filter hook output priority 0; policy drop; }'; sudo ip netns exec laboratorio-vpn nft 'add chain inet laboratorio input { type filter hook input priority 0; policy drop; }'
2. Liberar apenas a porta 1081 de saída e entrada no NFTables:
sudo ip netns exec laboratorio-vpn nft add rule inet laboratorio output oif lo accept; sudo ip netns exec laboratorio-vpn nft add rule inet laboratorio input iif lo accept; sudo ip netns exec laboratorio-vpn nft add rule inet laboratorio output ip daddr 10.200.0.1 tcp dport 1081 ct state new,established accept; sudo ip netns exec laboratorio-vpn nft add rule inet laboratorio input ip saddr 10.200.0.1 tcp sport 1081 ct state established accept
3. PROVA FINAL — Teste com SOCKS5 (Resultado esperado: IP Cloudflare):
sudo ip netns exec laboratorio-vpn curl --connect-timeout 15 --socks5-hostname 10.200.0.1:1081 https://icanhazip.com
PARTE 8, 9 & 11

📊 Captura Tcpdump & Destruição Limpa

Inspecionar os pacotes reais trafegando na interface virtual `veth-host` e destruir o laboratório limpo:
1. Inspecionar tráfego de pacotes na porta 1081 com tcpdump:
sudo tcpdump -i veth-host -nn tcp port 1081
2. Destruição completa e limpa do laboratório:
ssh -S /tmp/laboratorio-socks.sock -O exit psf@127.0.0.1 2>/dev/null || true; rm -f /tmp/laboratorio-socks.sock; sudo ip netns del laboratorio-vpn; sudo ip link del veth-host 2>/dev/null || true; sudo sysctl -w net.ipv4.ip_forward=0
