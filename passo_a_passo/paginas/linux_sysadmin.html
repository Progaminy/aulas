PASSO A PASSO 0 📦 Instalar Dependências & Pacotes Essenciais do Linux

Antes de executar tarefas de administração de sistemas, certifique-se de que os pacotes básicos estão atualizados e instalados no seu sistema (Ubuntu/Debian):
1. Atualizar o repositório e instalar ferramentas fundamentais:
sudo apt update && sudo apt install -y curl wget git htop net-tools psmisc procps
💡 Para que serve: Atualiza a lista de programas e instala os utilitários de inspecção de rede (`net-tools`), monitorização de processos (`htop`) e matadores de tarefas (`psmisc`/`killall`).

PASSO A PASSO 1 ⚙️ Gestão de Serviços com Systemd (Iniciar, Parar e Status)

O `systemd` é o gerenciador de sistema e serviços padrão do Linux. Veja como controlar qualquer serviço (ex: Nginx, SSH, Apache):
1. Verificar o status de um serviço (ex: ssh):
sudo systemctl status ssh --no-pager
💡 Para que serve: Mostra se o serviço está rodando (active/running), parado ou com erros.
2. Iniciar um serviço parado:
sudo systemctl start ssh
💡 Para que serve: Liga o serviço especificado em segundo plano imediatamente.
3. PARAR / ENCERRAR um serviço em execução:
sudo systemctl stop ssh
💡 Para que serve: Desliga e encerra o serviço com segurança sem reiniciar o sistema.

PASSO A PASSO 2 🛑 COMO ENCERRAR, PARAR OU MATAR PROCESSOS E SERVIDORES

Quando um servidor Python, Flask, Node.js ou script fica travado ou rodando em segundo plano, aprenda exatamente como localizá-lo e matá-lo:
1. Localizar o número do processo (PID) de um programa ou servidor (ex: python ou porta 5000):
pgrep -fa python || sudo lsof -i :5000
💡 Para que serve: Mostra a lista de todos os processos que contêm 'python' e o número do seu PID (Process ID).
2. Encerrar graciosamente um processo pelo número PID (ex: PID 1234):
kill 1234
💡 Para que serve: Envia o sinal SIGTERM (15) solicitando que o aplicativo salve dados e feche limpo.
3. FORÇAR E MATAR IMEDIATAMENTE um processo travado (SIGKILL -9):
kill -9 1234 || pkill -9 -f python
💡 Para que serve: Envia o sinal SIGKILL (9) que força o Kernel a exterminar o processo imediatamente sem desculpas.
4. Matar todos os processos que estejam ouvindo em uma porta específica (ex: porta 8080 ou 5000):
sudo fuser -k 5000/tcp
💡 Para que serve: Libera instantaneamente a porta 5000 travada matando o processo que a estava ocupando.

PASSO A PASSO 3 ⚡ Como Desligar, Reiniciar ou Encerrar o Sistema Linux

Diferentes formas de encerrar a máquina virtual ou computador de forma segura sem corromper o sistema de arquivos:
1. Desligar o computador imediatamente:
sudo shutdown -h now
💡 Para que serve: Desmonta os discos rígidos com segurança e desliga a energia do computador.
2. Reiniciar o sistema operacional:
sudo reboot
💡 Para que serve: Encerra todos os programas e reinicia o Linux limpo.
