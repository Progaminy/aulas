🔥 Criar Servidor Python Flask + Wi-Fi + Firewall no Windows

Tutorial completo para criar a pasta, escrever o script `servidor.py`, liberar a porta 5000 no Firewall do Windows e rodar o servidor Flask:
1. Entrar na pasta do usuário:
cd %USERPROFILE%
2. Criar a pasta meu_servidor:
mkdir meu_servidor
3. Entrar na pasta recém-criada:
cd meu_servidor
4 a 10. Escrever as linhas do script servidor.py via terminal:
echo from flask import Flask > servidor.py
echo app = Flask(__name__) >> servidor.py
echo @app.route('/') >> servidor.py
echo def home(): >> servidor.py
echo return 'Servidor rodando na rede Wi-Fi!' >> servidor.py
echo if __name__ == '__main__': >> servidor.py
echo app.run(debug=True, host='0.0.0.0', port=5000) >> servidor.py
11. Instalar a biblioteca Flask:
pip install flask
12. Ligar o servidor Flask:
python servidor.py
13. Descobrir o IP local no Windows:
ipconfig
14. Liberar a porta 5000 no Firewall (CMD como Admin):
netsh advfirewall firewall add rule name="Servidor Python" dir=in action=allow protocol=TCP localport=5000
📱 15. URL para Acessar do Celular ou Outro PC na mesma Wi-Fi:
http://192.168.1.100:5000
PASSO A PASSO 2

📂 Acessar & Baixar Arquivos de Pastas com Outro Dispositivo pela Wi-Fi

Como transmitir arquivos de uma pasta do computador/celular para qualquer outro dispositivo via navegador Wi-Fi:
1. Conectar ambos os aparelhos no mesmo roteador Wi-Fi.
2. Entrar na pasta que deseja disponibilizar (Windows):
cd /d "%USERPROFILE%\Desktop\Compartilhar"
Ou no Linux/Termux: cd ~/Downloads
3. Ligar o servidor HTTP nativo escutando em todas as placas (`0.0.0.0`):
python -m http.server 8000 --bind 0.0.0.0
4. Abrir o navegador no celular e digitar a URL com o seu IP:
http://192.168.1.100:8000

🐙 Clonar, Criar Repositório, Commit & Push no GitHub

Fluxo completo para enviar seus projetos para o GitHub Pages sem erros:
1. Clonar o repositório remoto para o computador:
git clone https://github.com/SeuUsuario/meu-projeto.git
2. Adicionar todas as alterações criadas:
git add .
3. Gravar o commit com mensagem explicativa:
git commit -m "feat: adicionar nova funcionalidade"
4. Enviar as alterações para o repositório no GitHub:
git push origin main

🐍 Resolver 'pip' e 'python' Não Reconhecidos no Windows

Soluções instantâneas quando o Prompt de Comando diz que `pip` ou `python` não são comandos válidos:
📌 Solução 1: Executar PIP usando o módulo do Python diretamente:
python -m pip install flask
📌 Solução 2: Usar o lançador oficial `py` do Windows:
py -m pip install flask
📌 Solução 3: Adicionar a pasta Scripts do Python ao PATH via PowerShell:
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";$env:LocalAppData\Programs\Python\Python311\Scripts", "User")

🐧 Iniciar Servidor Python no Linux / Termux (Da Instalação à URL)

Guia para atualizar pacotes, instalar Python, criar a pasta e subir o servidor no Linux/Android:
1. Instalar Python no Termux:
pkg update && pkg install python -y
Ou no Ubuntu/Debian: sudo apt update && sudo apt install python3 -y
2. Criar pasta e entrar nela:
mkdir -p ~/servidor_python && cd ~/servidor_python
3. Ligar o servidor na porta 8000 escutando a rede:
python -m http.server 8000 --bind 0.0.0.0
4. Descobrir o IP local do Linux:
hostname -I
📱 5. URL no Navegador:
http://192.168.1.100:8000

🔐 Configurar & Alterar Senhas de Usuários no Windows (`net user`)

Comandos para alterar, redefinir ou criar senhas de contas do Windows via terminal (Admin):
📌 Alterar senha de forma oculta (digitar senha sem aparecer no terminal):
net user NomeDoUsuario *
📌 Definir uma nova senha direta para o usuário:
net user NomeDoUsuario NovaSenha123
📌 Criar nova conta de usuário no Windows com senha:
net user NovoUsuario SenhaForte123 /add
PASSO A PASSO 7

⏰ Configurar Tempo de Sleep e Suspensão do Windows (`powercfg`)

Ajuste o tempo para a tela desligar ou o computador entrar em suspensão:
📌 Configurar tempo de Sleep/Suspensão na tomada para 30 minutos:
powercfg /change standby-timeout-ac 30
📌 Desligar a TELA do monitor na tomada após 15 minutos:
powercfg /change monitor-timeout-ac 15
🚫 DESATIVAR o Sleep do Windows (Nunca suspender na tomada):
powercfg /change standby-timeout-ac 0

🖼️ Mudar a Imagem de Fundo (Wallpaper) do Windows

Comandos para alterar a tela de fundo da Área de Trabalho pelo terminal:
📌 Abrir a tela de Configurações de Fundo do Windows 10/11:
start ms-settings:personalization-background
📌 Alterar a imagem de papel de parede via PowerShell:
powershell -command "$code = 'using System.Runtime.InteropServices; public class Wallpaper { [DllImport(\"user32.dll\", CharSet = CharSet.Auto)] public static extern int SystemParametersInfo(int uAction, int uParam, string lpvParam, int fuWinIni); }'; Add-Type $code; [Wallpaper]::SystemParametersInfo(20, 0, 'C:\Users\Public\Pictures\imagem.jpg', 3)"

🐘 Conectar PHP ao Banco MySQL (PDO) + Hashing Argon2ID

Boilerplate seguro em PHP para conexões de banco de dados e hash de senhas criptografadas:
1. Conexão PDO segura em PHP:
$pdo = new PDO("mysql:host=localhost;dbname=meudb;charset=utf8mb4", "root", "senha");
2. Criar Hash seguro de senha usando Argon2ID:
$hash = password_hash($senha, PASSWORD_ARGON2ID);
3. Verificar a senha digitada no Login:
if (password_verify($senhaDigitada, $hash)) { /* Acesso Concedido */ }
