📦 Instalação do Git & VS Code no Linux

🐉 1. Instalar VS Code Oficial via Repositório Microsoft
📌 Passo 1: Baixar chave GPG da Microsoft:
wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > packages.microsoft.gpg
📌 Passo 2: Instalar chave de segurança:
sudo install -D -o root -g root -m 644 packages.microsoft.gpg /etc/apt/keyrings/packages.microsoft.gpg
📌 Passo 3: Adicionar repositório oficial da Microsoft:
sudo sh -c 'echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/packages.microsoft.gpg] https://packages.microsoft.com/repos/code stable main" > /etc/apt/sources.list.d/vscode.list'
📌 Passo 4: Atualizar repositórios e instalar VS Code:
sudo apt update && sudo apt install code -y
📥 2. Instalar via Pacote .DEB Direto
📌 Baixar o arquivo .deb do VS Code:
wget -O code_latest_amd64.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"
📌 Instalar pacote .deb:
sudo dpkg -i code_latest_amd64.deb
🛠️ 3. Instalar e Configurar o Git
📌 Instalar Git:
sudo apt update && sudo apt install git -y
📌 Configurar nome de usuário no Git:
git config --global user.name "Seu Nome"
📌 Configurar e-mail no Git:
git config --global user.email "seu_email@exemplo.com"
