🐙 GitHub: Clonagem de Repositórios (Git Clone)

🚀 1. Comando Básico e Exemplos (Comando por Comando)
📌 Clonar repositório padrão via HTTPS:
git clone https://github.com/username/repository.git
📌 Clonar repositório via SSH:
git clone git@github.com:username/repository.git
📌 Clonar definindo o nome de uma pasta personalizada:
git clone https://github.com/username/repository.git minha-pasta
🐉 2. Passo a Passo Completo no Terminal (Executar 1 a 1)
📌 Passo 1: Instalar o Git se necessário:
sudo apt update && sudo apt install git -y
📌 Passo 2: Entrar na Área de Trabalho (Desktop):
cd ~/Desktop
📌 Passo 3: Clonar este repositório de Aulas:
git clone https://github.com/Progaminy/aulas.git
📌 Passo 4: Entrar na pasta do projeto clonado:
cd aulas
📌 Passo 5: Listar conteúdo detalhado da pasta:
ls -la
💡 3. Dicas Avançadas de Clonagem
📌 Clonar apenas a branch 'main':
git clone -b main https://github.com/username/repository.git
📌 Shallow Clone (apenas versão recente sem histórico antigo):
git clone --depth 1 https://github.com/username/repository.git
