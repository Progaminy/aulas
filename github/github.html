🔧 1. INSTALAÇÃO & PRÉ-REQUISITOS
sudo apt update && sudo apt install git -y
git: sistema de controle de versão. Essencial para comunicar com GitHub. 📁 qualquer diretório
git --version
Verifica se o Git foi instalado. Mostra a versão atual.

🔐 Porquê token? GitHub deixou de aceitar senha em linha de comandos. Token = senha segura gerada no site.

🔗 Criar Token (GitHub)
👤 2. CONFIGURAÇÃO GLOBAL (UMA VEZ)
git config --global user.name "SeuNome"
Define o nome que aparecerá nos commits. 📁 qualquer diretório
git config --global user.email "email@exemplo.com"
Email vinculado à conta GitHub.
🧬 3. CLONAR REPOSITÓRIO (OBTER CÓDIGO)
cd ~/Documentos
Significado: "change directory" → muda para a pasta Documentos. 📁 diretório onde quer guardar o projeto
git clone https://github.com/USER/REPO.git
Significado: "clone" → copia o repositório remoto inteiro para a sua máquina.
🔹 Cria automaticamente uma pasta com o nome do repositório. 📁 ~/Documentos (antes de executar)
cd REPO
Significado: Entra na pasta do repositório clonado. 📁 ~/Documentos/REPO
💡 Nota: Após o clone, o remote "origin" já fica configurado automaticamente.
🔁 FORMA 1 · TOKEN PEDIDO SEMPRE

⏳ A cada push, o terminal pede nome de usuário e token.

git init
Significado: "initialize" → cria um repositório Git vazio na pasta atual. 📁 dentro da pasta do projeto
git add .
Significado: "add" → adiciona todos os ficheiros (.) à área de stage (preparação para commit).
git commit -m "primeiro commit"
Significado: "commit" → cria uma fotografia do estado atual dos ficheiros. -m permite escrever a mensagem diretamente.
git branch -M main
Significado: renomeia a branch atual para "main" (padrão moderno do GitHub).
git remote add origin https://github.com/USER/REPO.git
Significado: "remote add" → liga o repositório local ao repositório remoto (GitHub). "origin" é o nome padrão dado ao link remoto.
git push -u origin main
Significado: "push" → envia os commits locais para o GitHub. -u define "origin main" como upstream padrão.
⚠️ Vai pedir Username (teu nick GitHub) e Password (cola o token).
💾 FORMA 2 · TOKEN GUARDADO (SEM REPETIR)
git config --global credential.helper store
Significado: ativa o armazenamento permanente de credenciais. Após o primeiro push bem-sucedido, o token fica salvo em disco (ficheiro ~/.git-credentials). 📁 qualquer diretório (configuração global)
git push -u origin main
🔐 Primeira vez: insere username + token. Depois nunca mais pede.
💡 Dica de segurança: O token fica guardado em texto plano. Use apenas em máquina confiável.
🔄 4. PUSH APÓS CLONE (ROTINA DIÁRIA)

📌 Sempre que fizer alterações e quiser enviar para o GitHub:

cd ~/Documentos/REPO
Significado: Navega até à pasta do repositório clonado. 📁 deve estar dentro da pasta do repositório
git status
Significado: "status" → mostra ficheiros modificados, novos ou na stage area. Boa prática antes de add.
git add .
Significado: Adiciona todas as alterações à área de stage.
git commit -m "descrição das alterações"
Significado: Regista as alterações localmente com uma mensagem descritiva.
git pull origin main
Significado: "pull" → puxa alterações do repositório remoto antes de enviar as suas (evita conflitos). 📁 dentro do repositório
git push origin main
Significado: Envia os seus commits para o GitHub. Se usou o "credential.helper store", não pede token novamente.
⚡ Resumo rápido: cd REPO → git add . → git commit -m "msg" → git pull origin main → git push origin main
